# 정답 없는 시뮬레이션 결과: 가상 사장님 10명 → 세그먼트 기준 찾기 (11/08)

> 시험용 가상 데이터예요. 실제 사장님 행동의 증거가 아니라, **분류 기준을 정하는 방법**을 시험한 결과예요.
> 기존 시뮬레이션(`run.mjs`)은 사장님마다 S1~S5 정답을 미리 정해 두고 규칙이 맞히는지 본 것이고, 이번에는 **정답 없이** 행동만 무작위로 정한 뒤 기록에서 기준을 찾았어요.
> 이 결과를 낸 코드(`open/personas.mjs` · `discover.mjs` · `segments.mjs`)는 클라우드 세션에서 실행했고 저장소에 올라가지 못했어요. 필요하면 이 문서의 방법대로 다시 만들어요.

## 1. 순서

| 단계 | 내용 |
|---|---|
| 1. 사장님 만들기 | 행동 축마다 10단계 값을 **축별로 따로 섞어** 10명에게 나눠 줌 → 축마다 10명이 모두 다르고, 축 사이 조합은 무작위. 기존 성격표 · 행동 기록은 읽지 않음 |
| 2. 돌리기 | 6개월 × 200판. 1~100번 판으로 기준을 만들고, 101~200번 판으로 확인 |
| 3. 상태 규칙 | 최근 4주 접속이 평소의 절반 이하 **또는** 35일 넘게 활동 없음 → **S5 이탈 위험** (유형이 아니라 상태라서 묶음에 안 섞음) |
| 4. 묶음 | 나머지를 행동 지표 10개로 k-평균. 묶음 수는 3~5개 중 실루엣 점수가 가장 높은 5개 (점수 0.44) |
| 5. 배분 | 묶음 평균 지표로 자동: 접속 가장 낮음 → 휴면, 소진 신고 가장 많음 → S4, 추천 수용 가장 높음 → S2, 구매액 가장 큼 → S3, 나머지 → S1 |
| 6. 규칙 | 세그먼트마다 뜻이 통하는 지표 1~2개. 기준값 = 그 묶음 평균과 가장 가까운 다른 묶음 평균의 중간 |
| 7. 확인 | 101~200번 판에서 규칙 결과와 묶음 결과 비교 + 매주 최근 8주 기록으로 다시 분류 (2주 연속 같을 때만 바꿈) |

### 행동 축 (사장님마다 다름)
| 축 | 값 |
|---|---|
| 앱 접속 | 하루 접속 확률 10% ~ 90%, 월 1회 1명 · 시간대(새벽 · 오전 · 브레이크 · 마감 후) · 사용 흐름(유지 6명 · 점점 멀어짐 2명 · 점점 익숙해짐 2명) |
| 알림 · 추천 | 알림 클릭 3% ~ 75% · 추천 그대로 따르기 2% ~ 80% · "기다리기" 따르기(알림 클릭률과 비슷하게) |
| 발주 습관 | 정해진 요일(월·수·금 / 월·목 / 화·금 / 월) 또는 2.2 ~ 12일마다 · 주 구매액 70만 ~ 350만 원 · 품목 5 ~ 16개 · 넉넉함 0.72 ~ 1.2 · 소진 신고 5% ~ 95% · 급발주 5% ~ 95% |
| 영수증 입력 | 발주의 40% ~ 98%를 영수증으로 남김 (월 1회 접속자는 몰아서) |

### 무작위가 아닌 부분
- 가게 이름은 기존 목록을 다시 씀 (이름표일 뿐, 행동과 관계없음)
- 각 축의 값 범위는 임의로 정함 (실제 통계 근거 없음 → KREI 조사로 보완 필요)
- "기다리기" 반응은 알림 클릭률에 묶음 (알림을 잘 누르면 기다리기도 잘 따른다고 가정)
- 시드 고정 → 매번 같은 10명. 하루하루 행동은 판마다 달라짐
- 축 사이 상관: 36쌍 평균 0.32 (10명 무작위 기대값 약 0.27, 우연 수준)
