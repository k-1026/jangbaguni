# 자영업자 카페 VOC 분석 결과 (11/12)

> 무엇: 팀원 3명이 자영업자 카페에서 캡처한 **333장**을 글로 바꿔 분류하고, 페인포인트 · 원가 계산 방식 · 구매처를 정리했다
> 앞 문서: [1111_bm_voc_process.md](1111_bm_voc_process.md) (VOC를 왜 · 어떻게 모으기로 했는지, 분류 기준 A · B · C)
> 개인정보: 캡처와 글자 인식 원문은 저장소 밖(구글 드라이브)에만 있음. 이 문서에는 닉네임 없이 요약과 다듬은 문장만 씀

## 0. 한 줄 요약

| 질문 | 답 |
|---|---|
| 사장님이 가장 아파하는 것 | **"메뉴 하나 팔면 얼마 남는지 모른다"** (원가 계산 59% · 남는 게 없다 40%). "언제 사야 할지"(7%)보다 훨씬 많음 |
| 원가는 어떻게 계산하나 | 영수증 · 메모로 **대충**, 또는 엑셀. 공통 불만: **재료값이 바뀔 때마다 손으로 다시 고쳐야** 함 |
| 메뉴 가격은 어떻게 정하나 | **감으로** ("옆집도 올렸으니 500원"). 올리면 손님이 끊길까 무서워서 몇 년째 못 올림 |
| 어디서 사나 | **거래처 · 납품업체**가 가장 많고, 그다음 도매시장 · 식자재마트. 식봄은 "비교용 · 소량 단가 확인"으로 언급 |
| 놓치면 안 되는 것 | 카페에 **살피와 거의 같은 무료 도구**(210개 품목 도매가 예측, 범위 표시)와 **직접 만든 원가 계산기 홍보 글**이 이미 여럿 있음 |
| BM에 주는 뜻 | 시세 예측만으로는 차별점이 약함 → **"재료값이 바뀌면 내 메뉴 원가율 · 올릴 가격이 자동으로"** 가 중심, 시세는 그 재료 |

## 1. 자료와 방법

| 항목 | 내용 |
|---|---|
| 자료 | 자영업자 카페 캡처 333장 (팀원별 151 · 112 · 70장) + 사장님이 올린 엑셀 원가계산표 1개 |
| 글로 바꾸기 | 윈도우 기본 한국어 글자 인식(무료, `tools/ocr/voc_ocr.ps1`), 작은 글씨는 3배로 키워 읽음 → 약 19만 자 |
| 분류 | ① 화면 잡음(좋아요 · 조회 · 광고 배너) 빼기 → ② 분류 기준(A 페인포인트 · B 원가 계산 방식 · C 구매처)별 낱말로 캡처마다 표시 → ③ 표시된 문장을 사람이 읽듯 다시 읽어 뜻 확인 · 대표 문장 고르기 |
| 숫자의 뜻 | **그 이야기가 나온 캡처 수**(전체 333장 중 몇 %). 한 캡처에 여러 이야기가 있으면 여러 곳에 셈 |

### 읽을 때 주의할 점
- **캡처 ≠ 글**: 긴 글 하나를 여러 장으로 캡처한 경우가 있어, 글 수는 333보다 적음
- **검색어 쏠림**: "원가 · 식자재 가격" 같은 낱말로 찾은 글이라 원가 이야기가 많이 나오는 건 당연한 면이 있음. 그래서 **비율보다 순서와 내용**을 볼 것
- **글자 인식 오류**: 몇 글자씩 틀림 (예: 식봄 → "식몸", 엑셀 → "엑•필"). 낱말 세기는 **실제보다 적게** 셀 수 있음 (특히 엑셀 · 식봄)
- **홍보 글이 섞임**: 원가 계산기 · 예측 도구를 만든 사람이 쓴 글이 10장 안팎. 사장님 고민 글과 따로 봐야 함 (6절)

## 2. 페인포인트 순위 (A)

| 순위 | 페인포인트 | 캡처 | 대표 목소리 (글자 인식 결과를 다듬음) |
|---|---|---|---|
| 1 | **원가 계산이 어렵다 · 원가율이 맞는지 모르겠다** | 195장 (59%) | "고기 600g 원가 5,280원, 이 계산 맞나요? 급해요" · "다들 원가율 몇 % 잡으세요?" (이런 확인 질문만 27장) |
| 2 | **재료값이 계속 오른다** | 179장 (54%) | "몇 달 전과 같은 걸 사는데 영수증 금액이 확 달라졌어요" · "어제는 대파, 오늘은 식용유가 또 뛰었네요" |
| 3 | **남는 게 없다 · 마진** | 133장 (40%) | "재료비 비중이 커지니 결국 제 인건비를 깎아 먹는 셈" · "오픈한 지 얼마 안 됐는데 지금은 적자" |
| 4 | 인건비 | 89장 (27%) | 4대보험 · 국민연금 사업주 부담이 계속 오름 |
| 5 | 임대료 · 고정비 (전기 · 가스) | 76장 (23%) | "냉방비는 그냥 여름 재료비라고 생각하기로 했어요" |
| 6 | 배달 수수료 · 배달앱 | 65장 (20%) | 배달은 용기 · 수수료 · 배달비까지 넣으면 원가율이 크게 오름 |
| 7 | **메뉴 가격 올리기 고민** | 63장 (19%) | "가격 올리면 손님 끊길까 봐 몇 년째 그대로" · "벌써 한 번 올려서 또 올리기가…" |
| 8 | 재고 · 폐기 · 로스 | 47장 (14%) | "대량으로 사 두는데 관리가 안 돼서 버리는 게 많아요" · 손질하면 고기 30% 가까이 빠짐 |
| 9 | 언제 · 얼마나 살지 | 23장 (7%) | 대량 구매 · 미리 사 두기 이야기는 있으나 적음 |

**흐름으로 보면 하나의 고리**: 재료값이 오름(2) → 메뉴 하나에 얼마 남는지 다시 계산해야 하는데 어려움(1 · 3) → 가격을 올릴지 못 정함(7). 사장님 글 대부분이 이 고리 안에 있음

[1109 고객 여정 지도](../journey/1109_customer_journey_map.html)의 Top 3(통계 · 팀 가정으로 만든 것)를 VOC 숫자와 맞춰 봄

|---|---|---|---|---|

## 4. 지금 원가를 계산하는 방식 (B)

| 방식 | 캡처 | 실제 모습 |
|---|---|---|
| 레시피 · 1인분 원가 직접 계산 | 71장 (21%) | 재료마다 g당 가격 × 사용량을 더함. "고춧가루 2큰술 196원 …" 식으로 손 계산 |
| 메모 · 노트 · 장부 · 영수증 | 30장 (9%) | "영수증 보고 대충 정리해 봤더니" · 메모장에 가상의 지출 적어 보기 |
| 원가 계산기 · 앱 · 프로그램 | 21장 (6%) | 대부분 **만든 사람의 홍보 글** (6절). 실제로 쓰는 사장님 이야기는 적음 |
| 감 · 대충 | 20장 (6%) | "메뉴 가격, 감으로 정합니다 — 옆집도 올렸으니 500원" |
| 세무사 · 부가세 | 13장 (4%) | "세무사님이 장부 보고 한숨" · 부가세 · 카드 수수료를 원가에 넣는지 헷갈림 |
| 엑셀 | 6장 (2%)* | "엑셀로 짜 봤는데 메뉴 바뀌고 재료 가격 변할 때마다 계속 손으로 고쳐야" · 핵심 품목 10개 가격을 매일 엑셀에 기록 |
| 포스(POS) | 4장 (1%) | 매출은 포스로 보지만 원가는 따로 |

\* 엑셀은 글자 인식이 자주 틀려 실제로는 더 많을 것

### 사장님이 실제로 쓰는 원가계산표 (팀원이 받은 엑셀)
- 칸: 상품명 · 가격 · **부가세 포함 가격** · 무게(g) 또는 개수 · 사용량 · **로스율(%)** · 로스 뺀 무게 · 사용 횟수 · **1회 사용 원가** · g당(개당) 원가
- 옆에 **로스율 계산기**(원래 무게 · 손질 후 무게 · 버린 양)가 따로 있음
- → 살피 메뉴 원가 기능에 **부가세 포함 여부 · 로스율** 칸이 필요하다는 근거

### 공통으로 귀찮아하는 것
1. **재료값이 바뀔 때마다 다시 계산**해야 함 (가장 많이 나옴)
2. **로스율**(손질 · 폐기)을 어떻게 넣는지 모름
3. 부가세 · 카드 수수료 · 배달 수수료 · 포장 용기를 **원가에 넣는지 헷갈림**
4. **적정 원가율 기준을 모름** → "몇 %가 맞나요?" 질문이 계속 올라옴 (답도 30% · 35% · 40%로 제각각)
5. **소매가로 원가를 잡는 실수**: 마트 · 인터넷 소매가로 계산하면 도매가와 20~50%p 차이가 남 (도매가 · 소매가 이야기 13장)

## 5. 어디서 사나 (C)

| 구매처 | 캡처 | 이야기 |
|---|---|---|
| **거래처 · 납품업체** | 41장 (12%) | 대부분 한 곳과 오래 거래. "업체에서 다음 주부터 생선 500~1,000원 오른다고 통보" |
| **도매시장 · 전통시장** | 24장 (7%) | "신선 재료는 가락시장에서, 공산품은 동네 할인마트에서" · "공판장" |
| 식자재마트 · 마트 | 13장 (4%) | 가까운 식자재마트에서 그때그때. 급할 때 마트 |
| 온라인몰 · 기타 | 12장 (4%) | 네이버 등 |
| 산지 · 농가 직거래 | 8장 (2%) | 재료비가 너무 올라 직거래를 알아보는 중 |
| 공동구매 | 4장 (1%) | "공동구매 모임 · 대량 구매 할인, 효과 있나요?" |
| **식봄** | 4장 (1%)* | 아래 |
| 쿠팡 · 창고형(코스트코 · 트레이더스) | 0장 | 이번 캡처에서는 나오지 않음 |

\* "식몸"처럼 잘못 읽힌 것 포함. 글자 인식 오류로 실제보다 적을 수 있음

### 식봄에 대한 목소리
- **좋은 점**: "한 곳만 오래 쓰다가 식자재 앱(식봄)으로 **비교해 보니** 품목마다 단가 차이가 커서 몇 개 바꿨더니 한 달 재료비가 꽤 줄었어요" · "비교 용도로만 써도 괜찮아요" · "소량이어도 단가가 괜찮아요"
- **걱정**: "새로 입점한 업체가 너무 싼데, 채소는 받아 보기 전엔 품질을 모르고 당일 교환 · 반품도 어려워서 고민" · "식봄 쓰다가 업체 바꿈. 아무리 싸도 품질이 들쭉날쭉하면 반품 스트레스"
- → 사장님에게 식봄은 **"주 거래처"라기보다 "단가 비교 · 일부 품목 바꾸기"** 용도로 많이 쓰임

## 6. 이미 있는 비슷한 도구 (경쟁 · 참고)

| 무엇 | 내용 | 살피와의 관계 |
|---|---|---|
| **도매가 예측 무료 도구** (카페 글로 홍보) | **210개 품목 도매가 예측**, 예측은 위아래 범위로 표시. 근거: "날씨가 며칠 앞선 신호", "소매가는 도매가보다 늘 늦다", "명절은 2~3주 전이 고점" | **살피의 시세 예측과 거의 같은 주장 · 기능.** 시세 예측만으로는 차별점이 약하다는 뜻 |
| 사장님이 직접 만든 원가 계산기 | 엑셀 원가계산기 배포, 요리 전용 원가 계산 사이트, 휴대폰용 원가 앱("여러 앱을 써 봤는데 마음에 드는 게 없어서 직접 만들었다") | 원가 계산 수요는 확실하지만, **무료 계산기는 이미 많음** |
| 원가 계산기 수요 조사 글 | "닭볶음탕 한 그릇 원가 4,364원 — 이런 계산기 있으면 쓰실래요? 휴대폰이 편해요, 컴퓨터가 편해요?" | 원하는 기능: g당 가격 자동 계산, 메뉴별 원가율 · 남는 돈, **재료값 하나 바꾸면 전체 메뉴 마진 다시 계산** |
| 원가 프로그램 (프랜차이즈용) · 식자재 발주 프로그램 | 이름만 언급 | 개인 가게에는 무겁다는 반응 |

※ 6절의 글은 **도구를 만든 사람이 쓴 홍보 글**이라 사장님 고민 숫자(2절)와 따로 봄

## 7. 비즈니스 모델에 주는 뜻

| 지금 살피 | VOC가 말하는 것 | 바꿀 방향 |
|---|---|---|
| 첫 화면 = 시세 대시보드 · 7일 예측 | 사장님 고민은 "언제 사나"(7%)보다 "얼마 남나 · 얼마 올리나"(59% · 19%) | **"내 메뉴 원가율 · 남는 돈"을 앞으로**, 시세는 그 숫자를 바꾸는 재료로 |
| 메뉴 원가 계산은 챗봇 · 나의 가게 안쪽 | "재료값 바뀔 때마다 손으로 고친다"가 가장 큰 귀찮음 | **시세가 바뀌면 내 메뉴 원가율이 자동으로 다시 계산**되는 알림 ("양파 +12% → 김치찌개 원가율 31% → 33%") |
| 가격 인상 판단 기능 없음 | "언제 · 얼마 올릴지 감으로" · 손님 끊길까 두려움 | **"원가율을 30%로 지키려면 얼마 올려야 하나"** 계산 + 근처 같은 메뉴 가격 참고 |
| 메뉴 원가에 로스율 · 부가세 칸 없음 | 실제 원가계산표에는 둘 다 있음 | 메뉴 원가에 **로스율 · 부가세 포함 여부** 추가 |
| 연결 대상: 식봄 vs 도매 사이트 고민 | 주 구매처는 거래처 · 도매시장. 식봄은 **비교용** | 살피 = **"내가 산 값이 도매 시세보다 비싼지" 알려 주는 중립 기준**. 영수증 단가 vs 도매 시세 비교 → 비싸면 다른 곳(식봄 등) 단가 비교로 연결 |
| 시세 예측 = 핵심 차별점 | 비슷한 무료 도구가 이미 있음 | 차별점은 예측 자체가 아니라 **"우리 가게 메뉴 · 영수증과 연결된 숫자"** |

**슬라이드 한 줄**: 사장님은 "언제 살까"보다 "이 가격에 팔아도 남나"를 더 자주 묻는다.
