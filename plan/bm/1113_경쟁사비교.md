## 0. 한 줄 요약

- **원가 계산 도구**(원까 · 키친코스트)와 **시세 도구**(KAMIS · 가락시세)는 각각 있지만, 둘을 **"내 영수증 · 내 메뉴"로 잇는 도구는 없음**
- 가장 가까운 경쟁자는 **원까**: 영수증 OCR → 레시피 원가까지 함. 다만 시세 연동 · 예측이 없음
- 살피만 가진 것: **다음 주 시세 예측 + 대구 기준 + 내 메뉴 원가율 연결**

## 2. 가중치 (VOC 근거)

| 기능 | 가중치 | 근거 |
|---|---|---|
| 레시피(g) 원가 계산 | 3 | 원가 계산이 어렵다 59% ([VOC](1112_voc_analysis.md)) |
| 재료값 바뀌면 원가율 자동 갱신 | 3 | 재료값 바뀔 때마다 손으로 고침 |
| 영수증 · 명세서 사진 자동 입력 | 2 | 손으로 다시 입력하는 귀찮음 |
| 목표 원가율 → 판매가 제안 | 2 | 가격 인상 고민 19% |
| 다음 행동 제안 (대체 재료 · 가격 인상) | 2 | 남는 게 없다 40% |
| 시세 조회 · 예측 · 채점 공개 · 대구 시세 · 싸게 샀나 · 구매처 · 알림 | 각 1 | 재료값 오름 54%, 언제 살지 7% |

팀 가정값. 엑셀 '가중치' 시트에서 바꾸면 점수가 다시 계산됨

## 4. 발표에 쓸 말

- "시세는 누구나 보여 주고, 원가 계산기도 이미 많다. **살피는 시세를 내 영수증 · 내 메뉴 원가율에 이어 '다음 주에 뭘 바꿀지'까지** 말해 준다"
- 원까(영수증 → 원가)는 "이미 있다 = 니즈가 있다"의 근거로 쓰고, 차이는 **시세 예측 · 대구 · 채점 공개**로 설명
