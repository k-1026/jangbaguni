## 1. 시장 규모 (TAM · SAM · SOM)

| 구분 | 정의 | 업체 수 | 연 매출 기회 |
|---|---|---|---|

| **TAM** | 전국 음식점 · 주점이 모두 구독한다면 | 788,862곳 | **약 1,884억 원** |
| SAM 참고 | 대구 음식점 · 주점 전체 (인구 비중 추정) | 약 36,362곳 | 약 87억 원 |

- SOM = 도입 가게 × (월 구독료 × 12 + 월 제휴 구매액 × 12 × 수수료율)

- 시장은 크지만 살피가 실제로 벌 수 있는 돈은 작음 → 대구에서 쓰임을 증명한 뒤 다른 지역 · 업종으로 넓히는 게 전제

## 2. 단위 경제성 (가게 1곳 기준)

### 2-1. 가정값 (⚠️ 모두 설문 · 운영 전)

| 항목 | 값 | 근거 |
|---|---|---|
| 월 구독료 | 19,900원 | 11/6 발표 예시 |
| 월 제휴 수수료 수입 | 9,000원 | 월 제휴 구매 30만 원 × 3% |
| 결제 수수료율 | 3.3% | 정기 결제 수수료 근사 |
| 영수증 AI 호출 | 월 30장 × 30원 | 하루 1장, 유료 모델 근사 (지금은 무료 한도) |
| 알림톡 | 월 30건 × 8원 | 아침 브리핑 하루 1건 |
| 서버 · DB | 가게당 월 500원 | Vercel · Supabase 비용 ÷ 가게 수 |
| 월 해지율 | 5% | 평균 20개월 유지 |
| 월 마케팅 비용 | 100만 원 | 카페 홍보 · 상인회 방문 인건비 환산 |
| 월 도달 가게 | 500곳 | 대구 한식 19,156곳 중 |
| 도달 → 무료 가입 | 10% | |
| 무료 → 유료 | 15% | |

### 2-2. 결과

| 항목 | 값 | 계산 |
|---|---|---|
| **객단가 (ARPU)** | **28,900원 / 월** | 구독료 + 제휴 수수료 |
| 가게당 월 변동비 | 약 2,594원 | AI 호출 900 + 알림톡 240 + 서버 500 + 결제 수수료 954 |
| 공헌이익 (월) | 약 26,306원 (91%) | 객단가 − 변동비 |
| **전환 깔때기** | 500곳 → 무료 50곳 → **유료 7.5곳 / 월** | 1년이면 약 90곳 ≈ SOM 1년차 96곳 (두 시트가 맞음) |
| **CAC** | **약 133,333원** | 월 마케팅 100만 원 ÷ 월 신규 유료 7.5곳 |
| LTV | 약 526,126원 | 공헌이익 × 20개월 |
| **LTV ÷ CAC** | **약 3.9배 → 좋음** | 3배 이상이면 건강하다고 봄 (흔히 쓰는 기준) |
| **CAC 회수 기간** | **약 5.1개월** | 12개월 안이면 좋음 |

### 2-3. 민감도 ① LTV ÷ CAC (세로: 월 해지율 / 가로: 월 구독료)

| 해지율 \ 구독료 | 9,900원 | 14,900원 | 19,900원 | 29,900원 |
|---|---|---|---|---|
| 3% | 4.2 | 5.4 | 6.6 | 9.0 |
| **5%** | 2.5 | 3.2 | **3.9** | 5.4 |
| 8% | 1.6 | 2.0 | 2.5 | 3.4 |
| 10% | 1.2 | 1.6 | 2.0 | 2.7 |

- **해지율이 구독료보다 더 크게 흔듦**: 구독료를 1만 원 올리는 것보다 해지율을 5% → 3%로 낮추는 효과가 큼
- 구독료 9,900원이면 해지율 5%에서도 3배 미만 → 저가 전략은 해지율을 3% 안팎으로 지켜야 가능

### 2-4. 민감도 ② CAC (세로: 무료 → 유료 전환율 / 가로: 월 마케팅 비용)

| 전환율 \ 마케팅비 | 50만 원 | 100만 원 | 150만 원 | 300만 원 |
|---|---|---|---|---|
| 5% | 200,000 | 400,000 | 600,000 | 1,200,000 |
| 10% | 100,000 | 200,000 | 300,000 | 600,000 |
| **15%** | 66,667 | **133,333** | 200,000 | 400,000 |
| 25% | 40,000 | 80,000 | 120,000 | 240,000 |

- 도달 수가 같으면 마케팅비를 늘려도 CAC만 오름 → 돈보다 **무료 → 유료 전환율**(첫 영수증 경험)을 올리는 게 먼저

## 3. AI 리서치 숫자 검증법

AI(검색 · 요약)가 가져온 숫자를 그대로 쓰지 않고 아래 절차로 확인함

| 단계 | 할 일 | 이번에 실제로 걸린 것 |
|---|---|---|
| ① 1차 출처 열기 | AI 요약이 아니라 통계표 · 보도자료 · 앱 소개 원문을 직접 연다 | 처음엔 검색 요약만 보고 씀 → 원문(농식품부 보도자료 · aT FIS 표)을 열어 다시 확인 |
| ② 숫자 · 단위 · 범위 맞추기 | 단위(원 · 백만 원 · 억), 대상 범위 | **"일반음식점 식재료비 40.7%"는 원문상 "외식업" 기준** → 이름 고침. **788,862곳은 "음식점 및 주점업"(주점 · 카페 포함)** → 이름 고침 |
| ③ 기준 연도 | 조사 연도와 실적 연도를 나눔 | "2025년 조사 = 2024년 실적"으로 표기 |
| ④ 다른 출처와 교차 | 다른 기관 · 기사 1곳 이상 같은 숫자인지. 운영사 발표는 B까지 | 평균 매출 · 영업이익률: 농식품부 + 뉴시스 일치 |
| ⑤ 계산으로 앞뒤 맞추기 | 다른 숫자로 다시 계산 | 업체 수 788,862 × 평균 매출 2억 5,526만 원 = 201.4조 원 vs 서비스업조사 전체 매출 198.9조 원 → **비율 1.012, 차이 1.2%로 맞음** (서로 다른 조사인데 앞뒤가 맞음) |

**등급**: A = 1차 출처 직접 확인 + (교차 1곳 이상 또는 그 자체가 공식 원문) · B = 원문 확인 또는 교차 중 하나 · C = 둘 다 없음 / 팀 가정 / 출처 불명 인용

| 숫자 | 값 | 쓰인 곳 | 등급 | 확인한 것 · 남은 일 |
|---|---|---|---|---|
| 전국 음식점 및 주점업 사업체 수 | 788,862곳 (2024) | TAM | **A** | [aT FIS 표](https://atfis.or.kr/fip/front/M000000268/stats/service.do) 원문(원자료 서비스업조사). 주점 · 카페 포함 |
| 외식업체 평균 연매출 | 2억 5,526만 원 (2024 실적) | 1곳 기준 | **A** | [농식품부 보도자료](https://www.mafra.go.kr/bbs/home/792/577439/artclView.do) 원문 + [뉴시스](https://www.newsis.com/view/NISX20260328_0003567838). 표본 3,138곳 |
| 외식업 식재료비 비중 | 40.7% (2024 실적) | 1곳 기준 | **A** | 같은 원문. 예전 문서의 "일반음식점"은 틀린 이름 |
| 외식업 영업이익률 | 8.7% (2024 실적) | 1곳 기준 | **A** | 같은 원문 + 뉴시스 |
| 대구 · 전국 인구 | 236만 · 5,120만 명 | SAM 참고 | C | 근사값. KOSIS 대구 사업체 수로 바꾸면 필요 없음 |
| **대구 한식음식점 수** | **19,156곳** | **SAM** | **C** | 브랜드키트 기획서에서 가져옴, **원출처 · 연도 못 찾음 → KOSIS로 확인 (가장 급함)** |
| 구독료 · 도입률 · 제휴 · 절감 · 단위경제 가정 | 여럿 | SOM · 단위경제 | C | 설문 · 운영 전. 발표에서 "가정" 표시 |
| 키친코스트 Pro 가격 | 월 19,900 · 연 89,000 · 평생 49,900원 | 경쟁사 비교 | A | App Store 원문 |
| 원까 출시 · 광고 제거 가격 | 2025-10 · $12.99 | 경쟁사 비교 | A | App Store 원문 |
| 시세.com 품목 수 | 55~73개 | 경쟁사 비교 | A | 페이지 원문 (날마다 다름) |
| 식봄 AI 가격 비교 상품 수 | 20만여 개 | 경쟁사 비교 | B | CJ 뉴스룸(운영사 쪽) + 브랜드키트. 운영사 발표라 B까지 |
| 식봄 외식업자 4분의 1 이용 | 1/4 | 경쟁사 비교 | B | 디지털데일리 검색 요약 + 브랜드키트. 원문 열면 A 가능 |
| 카페 예측 도구 210개 품목 | 210개 | 경쟁사 비교 | C | 카페 홍보 글 캡처. 도구 이름 · 주소 미확인 |
