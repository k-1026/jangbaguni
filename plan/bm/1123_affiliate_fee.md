# 쿠팡 파트너스 · 네이버 쇼핑 커넥트 수수료율 확인 (11/23)

> 무엇: "비싸게 샀어요 → 더 싼 곳" 연결에 붙일 수 있는 제휴 프로그램 두 곳의 수수료율 · 조건을 확인하고, 시장 규모 시트의 **제휴 수수료 0원(11/17)**을 바꿀지 정함
> 앞 문서: [시장 규모 시트](1113_시장규모시트.md) "11/17에 바뀐 것" · [BM 캔버스](1112_bm_canvas.md) ② 제휴 수수료 · [BM 질문 과정](1111_bm_voc_process.md)
> 화면: 11/23부터 구매하기 = 판매처 선택(식봄 · 쿠팡 · 마켓컬리 · 이마트몰), 영수증 "더 싼 곳"은 식봄만

---

## 0. 한 줄 요약

**시장 규모 · 구독료 계산은 지금처럼 제휴 수수료 0원으로 둔다.** 쿠팡은 약 3%(팀 확인값 · 공식 요율표는 로그인해야 보임), 네이버 쇼핑 커넥트는 판매자가 상품마다 정하는 방식이라 고정 요율이 없고 크리에이터 채널 심사가 필요하다. 둘 다 소매가라 원가 계산과도 잘 안 맞는다 → **"추가로 생길 수 있는 돈"으로만** 발표에서 언급.

---

## 1. 확인한 것

| | 쿠팡 파트너스 | 네이버 쇼핑 커넥트 |
|---|---|---|
| 방식 | 쿠팡 상품 링크 → 24시간 안 구매하면 수수료 | 네이버 브랜드 커넥트 안의 제휴 링크. 판매자가 수수료를 정한 상품만 링크 가능 (2025-07-23 정식 출시) |
| 수수료율 | 카테고리별 **약 1~3%**. 식품은 **약 3%로 팀이 확인** (블로그 정리에는 식품 · 생활용품 약 2%, 패션 · 뷰티 최대 3%, 가전 1%로 나옴) | **상품마다 판매자가 정함** (보통 3% 이상이라는 글이 많음, 출처마다 다름). 링크 뒤 24시간 안 다른 상품 구매 시 간접 실적 1.8% |
| 공식 확인 | ❌ 요율표는 파트너스 센터 로그인 뒤에만 보임 → **가입 뒤 직접 확인 필요** | ❌ 브랜드 커넥트 고객센터 문서에서 확인 필요 |
| 가입 조건 | 누구나 가입, 활동 뒤 최종 승인 | 크리에이터 채널 심사 (베타 때 블로그 이웃 1천 · 전월 방문 1만 기준이라는 자료) → **살피 같은 앱 · 웹사이트가 쓸 수 있는지 불확실** |
| 연결되는 곳 | 쿠팡 (외부 사이트에서 링크 가능) | 네이버 쇼핑 안 |
| 세금 | 개인은 사업소득 원천징수 3.3% | 개인 원천세 3.3%, 면세 사업자는 정산 불가라는 자료 |

- 11/20 일정 "쿠팡 파트너스 가입"은 끝남 → **파트너스 센터에 로그인해서 식품(신선식품) 실제 요율을 한 번 캡처해 두기** (발표 질문 대비)
- 식봄 · 마켓컬리 · 이마트몰: 공개 제휴 프로그램 확인 안 됨 (11/17 판단 그대로)

---

## 2. 살피에 붙이면 얼마인가 (예시)

영수증 "더 싼 곳" 예: 양파 15kg 망 17,990원을 쿠팡에서 샀다고 가정

| 가정 | 값 |
|---|---|
| 1건 구매액 | 17,990원 |
| 쿠팡 식품 수수료 3% | **약 540원** |
| 사장님 1명이 한 달에 링크로 사는 액수 (가정) | 30만 원 → 월 9,000원 (3%) |

- 30만 원은 **출처 없는 가정(C)**이라 11/17에 뺀 숫자와 같음. 사장님이 실제로 링크를 눌러 사는지 근거가 없음
- 구독료 월 19,900원과 비교하면 30만 원을 링크로 사도 구독료의 절반 안쪽(약 45%)

## 3. 정한 것

| 항목 | 결정 |
|---|---|
| 시장 규모 · SOM · 단위 경제 | **제휴 수수료 0원 그대로** (구독만) |
| 발표 | "제휴 링크(쿠팡 파트너스 약 3%)는 **추가 수익 가능성**, 계산에는 넣지 않음"이라고 한 줄 |
| 화면 | 쿠팡 링크를 파트너스 링크로 바꾸면 **"쿠팡 파트너스 활동으로 수수료를 받을 수 있어요"** 같은 대가성 안내를 링크 옆에 붙여야 함 (공정위 추천 · 보증 심사지침) |
| 네이버 쇼핑 커넥트 | 지금은 쓰지 않음 (채널 심사 · 판매자별 요율 · 네이버 안으로만 연결) |
| 중립성 | 수수료가 있어도 **목록 순서는 kg당 가격순 그대로** (수수료 많은 곳을 위로 올리지 않음) — [BM 질문 과정](1111_bm_voc_process.md) "수수료를 받으면 중립성도 깨짐" |
