## 1. 시세: 지금 → 바꿀 것

### 지금 공식 (계수는 감으로 정한 값)
```
7일 변화율(%) = 0.5 × 2주 추세  −0.25 × 반입량 변화율  + 날씨 가점 + 공휴일 가점 + 행사 가점
범위 = 변화율 ± (2 + 일별 등락률 표준편차 × 1.5)
```

| 요인 | 계산 방법 | 영향 범위 |
|---|---|---|
| 2주 가격 | 최근 2주 하루 평균 변화(원/kg) × 7 ÷ 2주 평균 가격 × 100 × 0.5 | −10% ~ +10% |
| 반입량 | −0.25 × 반입량 변화율 (최근 3거래일 평균 vs 그 전 10거래일 평균) | −6% ~ +6% |
| 날씨 (대구, 지난 7일) | 비 30mm 이상이면 잎채소 +3, 그 외 +1.5 / 영하 3도 이하인 날이 있고 추위에 약한 품목이면 +2 / 33도 이상인 날이 3일 이상이면 +2 | 조건을 모두 더함 |
| 공휴일 (7일 안) | 설 · 추석 +4, 그 외 공휴일 +2 | 0 ~ +4% |
| 행사 (7일 안) | 대구 행사가 5개 이상이면 +1 | 0 ~ +1% |

- 결과 문구: 합계 +2% 이상이면 "오를 가능성", −2% 이하면 "내릴 가능성", 그 사이는 "비슷할 가능성"

### 바꾼 공식 (구조는 같고, 항목 2개 추가 + 계수는 데이터로)
```
7일 변화율(%) = a_g × 2주 추세
              + b_g × 반입량 변화율
              + c_g × 계절 변화      ← 새로
              + d_g × 되돌림         ← 새로
              + 날씨 · 공휴일 · 행사 가점 (처음엔 지금 값 그대로, 2단계에서 계수로)
              + e_g (그룹 기본값)
```
- `g` = 품목 그룹. 그룹마다 계수 세트가 하나씩 있음

| 항목 | 계산 | 왜 넣나 |
|---|---|---|
| 2주 추세 | 최근 2주 하루 평균 변화 × 7 ÷ 2주 평균 × 100 (지금과 같음, 0.5는 a_g가 대신함) | 오르던 건 조금 더 오르는 경향 |
| 반입량 변화율 | 최근 3거래일 평균 ÷ 그 전 10거래일 평균 − 1 (지금과 같음) | 시장에 들어오는 양이 줄면 오름 |
| **계절 변화** | 지난 해들의 같은 주(오늘 → 7일 뒤) 평균 변화율 | 채소값은 해마다 같은 시기에 비슷하게 움직임 |
| **되돌림** | 오늘 가격 ÷ 지난 365일 평균 − 1 (%) → d_g는 음수일 것으로 예상 | 평소보다 너무 비싸면 내려올 가능성이 큼. 지금은 꼭대기에서 "더 오른다"고 틀리기 쉬움 |

### 품목 그룹 (계수를 같이 쓰는 묶음)
| 그룹 | 품목 | 특징 |
|---|---|---|
| 잎채소 | 배추 · 양배추 · 상추 · 깻잎 · 시금치 | 비 · 한파에 민감, 보관이 짧아 변동 큼 |
| 뿌리채소 | 양파 · 무 · 당근 · 감자 | 저장이 돼서 변동이 느림 |
| 양념채소 | 대파 · 청양고추 · 건고추 · 마늘 | 산지 날씨 · 작황 영향 큼 |

### 계수 맞추는 방법
1. 그룹별로 과거 날짜마다 (위 항목 4개 → 실제 7일 뒤 변화율) 표를 만듦
2. 최소제곱 회귀로 a_g ~ e_g를 구함. **학습 2021~2024, 확인 2025~2026** (확인 기간은 계수 정할 때 안 씀)
3. 계수가 상식과 반대(예: 반입량이 늘었는데 오름)면 그 항목은 빼고 다시 맞춤 → 설명이 말이 되게 유지

### 범위 (적중률 70% → 80%)
- 범위 = 예측 변화율 + **과거 오차의 분위수**. 오차 = 실제 변화율 − 예측 변화율 (학습 기간)
  - 1단계 70%: 오차의 15% ~ 85% 분위 사이
  - 2단계 80%: 오차의 10% ~ 90% 분위 사이
- 그룹별 · 계절별(여름 장마철은 넓게)로 따로 잼
- 지금 방식(± 2 + 표준편차 × 1.5)은 근거가 없어 실제 적중률을 모름 → 바꾼 방식은 적중률을 바로 잴 수 있음

### 채점 (확인 기간에서)
| 지표 | 뜻 | 목표 |
|---|---|---|
| **범위 적중률** | 실제 7일 뒤 가격이 범위 안에 든 비율 | 1단계 70% → 2단계 80% |
| 범위 폭 | 평균 ±몇 %인지 | 같은 적중률이면 좁을수록 좋음 |
| 방향 적중률 | 오를/내릴/비슷할 문구가 맞은 비율 | 보조 지표 |
| 평균 오차 | 예측 변화율과 실제 변화율 차이 (%p) | 보조 지표 |

### 비교할 것 (발표 슬라이드 "예측 모델 2종과 오차 비교")
| | 내용 | 설명 가능? |
|---|---|---|
| 지금 공식 | 감으로 정한 계수 | ✅ |
| **모델 ① 회귀 공식** | 위의 바꾼 공식 (계수를 데이터로) | ✅ 그대로 |
| **모델 ② 부스팅** | 같은 입력으로 학습 (LightGBM 등) | 이유 설명은 ①로 보여 줌 |

→ 셋 다 같은 확인 기간 · 같은 채점표로 비교하고, 범위 적중률을 맞추면서 폭이 가장 좁은 쪽을 기본 예측으로 씀

## 2. 판매량: 지금 → 바꿀 것

### 지금 공식
```
내일 그릇 수 = 최근 4주 평균 + 요일 차이 + 최근 흐름 × 0.5 + 공휴일
범위 = 지난 4주 오차로
```

### 바꾼 공식 (곱하기 구조: "평소보다 몇 배")
```
내일 그릇 수 = 기본값 × 공휴일 배수 × 날씨 배수 × 행사 배수 × 월급날 배수
기본값 = 최근 4주 같은 요일 평균 × (1 + 최근 흐름 × k)
```
| 항목 | 계산 | 메뉴마다 다름? |
|---|---|---|
| 기본값 | 최근 4주 **같은 요일** 평균 (요일 차이를 따로 더하지 않음) | - |
| 공휴일 배수 | 공휴일 · 연휴 앞뒤 날의 평소 대비 판매 | 가게 위치별 (오피스 상권 ↓, 주거 상권 ↑) |
| **날씨 배수** | 비 · 폭염(33도 이상) · 한파(영하 3도 이하) 날의 평소 대비 판매 | **예**: 국물류는 비 · 추위에 ↑, 냉면류는 더위에 ↑, 홀 손님 전체는 비에 ↓ |
| **행사 배수** | 대구 행사(야구 홈경기 · 축제)가 있는 날, 가게 주변이면 | 가게 위치별 |
| **월급날 배수** | 25일 전후 · 월초 3일의 평소 대비 판매 | 상권별 |
- 배수는 가게 기록이 쌓이면 가게별로, 그 전에는 **메뉴 종류별 기본값**을 씀
- 범위: 과거 오차의 분위수 (시세와 같은 방식, 70% → 80%)

### 가상 POS로 시험하는 방법
1. 가상 가게(가상 사장님 시뮬레이션의 10곳)에 메뉴 3~5개씩 주고, **정답 배수**(예: 국밥 비 오는 날 ×1.15)를 숨겨서 6개월 판매 기록을 만듦
2. 바꾼 공식이 기록만 보고 그 배수를 얼마나 되찾는지 확인
3. 채점: 범위 적중률 · 평균 오차(그릇) · "주문 목록이 모자란 날" 수 → 지금 공식과 비교
