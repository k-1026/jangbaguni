## 0. 한 줄 요약

| 질문 | 답 |
|---|---|
| 부스팅이 더 나은가? | **네.** 새 요인을 넣은 부스팅이 시험 기간에서 정반대 **26.2% → 23.0%**, 평균 오차 **19.58 → 18.55%p**, 방향 맞음 **45.4% → 51.5%** |
| 미리 정한 채택 기준(정반대 · 평균 오차 둘 다 낮음)을 넘었나? | **넘음.** 해마다 굴려 검증한 3개 기간 모두 정반대 · 오차가 지금 공식 이하 |
| 무엇이 효과가 컸나? | 같은 요인 3개만으로도 조금 나아지고(오차 19.01), **새 요인(명절까지 남은 날 · 계절 · 변동성 · 최근 3일 · 비 · 월)**을 넣으면 더 나아짐 |
| 서울 도매가는? | 방향 맞음은 더 오르지만(52.7%) 정반대가 오히려 조금 늘어 **보류**. 자료가 2025-08까지라 시험 기간이 짧음 |
| 남은 일 | 팀 확인 → 채택하면 주 1회 학습 + 결과(JSON)만 사이트가 읽는 구조로 연결 |

## 1. 비교 조건

| 항목 | 내용 |
|---|---|
| 자료 | `backtest.py` 와 같음: 북부도매 야채 15개 경락가 · 반입량 · 대구 날씨 (2021-03 ~ 2026-11), 이틀마다 기준일, 7일 뒤 첫 거래일 |
| 기간 | **학습 2021~2024** (그중 2024는 부스팅 나무 수를 고르는 데만 씀) / **시험 2025-01 ~ 2026-11** (어떤 방법도 안 봄), 4,107건 |
| 채점 | 방향 맞음 (오를 +2%↑ · 유지 · 내릴 −2%↓) · **정반대** · **평균 오차** · "그대로" 오차 |
| 채택 기준 (11/12 사전에 정함) | 시험 기간에서 **정반대와 평균 오차가 둘 다** 지금 공식보다 낮을 것. 방향 맞음은 참고 |

### 비교한 방법

| 방법 | 내용 |
|---|---|
| 지금 공식 | 4주 평균과의 차이 × −0.3 + 반입량 × −0.1 + 대구 날씨 (`analysis.py`) |
| 절대오차 회귀 | 같은 요인 3개, 계수를 "평균 오차"를 줄이도록 맞춤 |
| 부스팅 · 요인 3개 | 같은 요인 3개 + 품목, 나무 여러 개로 학습 (절대오차 목표) |
| **부스팅 · 새 요인** | + 최근 2주 흐름 · 비 · 한파 · 폭염 일수 · 변동성 · 최근 3일 변화 · **계절**(지난 해 같은 날의 7일 변화) · **명절까지 남은 날** · 월 |
| 부스팅 · + 서울 도매가 | + KAMIS 서울 도매 조사가 (7일 변화 · 4주 평균과의 차이 · 대구와의 가격 차) |

- 부스팅은 `salpi_agent/gbdt.py` (numpy만 쓰는 히스토그램 부스팅, LightGBM 방식). 이 PC의 보안 정책이 LightGBM · scikit-learn DLL을 막아 직접 구현함 → 외부 라이브러리가 필요 없어 GitHub Actions 등에서도 그대로 돌아감
- 명절 날짜(설 · 추석 2021~2026)는 `boost_compare.py` 의 `MAJOR_HOLIDAYS` 표

## 2. 결과

### 시험 2025-01 ~ 2026-11 (4,107건)

| 방법 | 방향 맞음 | 정반대 | 평균 오차 |
|---|---|---|---|
| 지금 공식 | 45.4% | 26.2% | 19.58%p |
| 절대오차 회귀 (요인 3개) | 45.7% | 25.1% | 19.40%p |
| 부스팅 · 요인 3개 | 49.3% | 25.1% | 19.01%p |
| **부스팅 · 새 요인 (절대오차)** | **51.5%** | **23.0%** | **18.55%p** |
| 부스팅 · 새 요인 (제곱오차) | 51.6% | 24.9% | 18.65%p |
| 부스팅 · + 서울 도매가 | 52.7% | 24.0% | 18.48%p |

"그대로"라고 했을 때 오차: 20.43%p

### 서울 자료가 있는 기간만 (2025-01 ~ 2025-08, 1,496건)

| 방법 | 방향 맞음 | 정반대 | 평균 오차 |
|---|---|---|---|
| 지금 공식 | 46.4% | 25.6% | 19.80%p |
| 부스팅 · 새 요인 | 52.1% | **21.3%** | 18.60%p |
| 부스팅 · + 서울 도매가 | **54.9%** | 24.1% | **18.33%p** |

### 해마다 굴려 검증 (그해 전까지로 학습 → 그해 시험)

| 시험 연도 | 지금 공식 정반대 · 오차 | 부스팅(새 요인) 정반대 · 오차 | 방향 맞음 |
|---|---|---|---|
| 2023 | 26.1% · 20.34%p | 26.0% · 20.06%p | 46.8 → 48.4% |
| 2024 | 28.8% · 19.63%p | 27.0% · 18.86%p | 43.3 → 48.9% |
| 2025~26 | 26.2% · 19.58%p | 23.0% · 18.55%p | 45.4 → 51.5% |

- 세 기간 모두 부스팅이 지금 공식 이하. 2023은 차이가 작음 (학습 자료가 2년뿐)

### 부스팅이 많이 쓴 요인 (나누는 데 쓴 비율)
품목 20% · **명절까지 남은 날 10%** · 4주 평균과의 차이 8% · 변동성 7% · 비 7% · 월 6% · 계절 6% · 반입량 6% · 2주 흐름 6% · 최근 3일 6%

- 품목마다 움직임이 다르고, 명절이 다가올 때의 변화가 큼 → 지금 공식에는 둘 다 없음 (공휴일 가점은 감으로 정한 값이고 채점 전)

## 3. 해석과 한계

| 항목 | 내용 |
|---|---|
| 왜 나아졌나 | 요인끼리 섞인 효과(품목 × 계절 × 명절)와 직선이 아닌 관계를 나무가 잡음. 같은 요인 3개만으로도 좋아진 건 품목별 차이 때문 |
| 회귀가 아니라 절대오차 목표인 이유 | 제곱오차는 크게 튀는 값에 끌려가 정반대가 늘어남 (부스팅에서도 제곱오차 24.9% vs 절대오차 23.0%) |
| 서울 도매가 | 방향 맞음 · 오차엔 도움이 되지만 정반대가 조금 늘고, 자료가 2025-08에서 끊김 → aT API로 최근분을 받아 다시 볼 것 |
| 한계 ① | 무작위 시드 1개로 본 결과. 시드를 바꿔 몇 번 더 돌려 차이가 유지되는지 확인 필요 |
| 한계 ② | 방향 맞음 51%는 여전히 절반 수준. 큰 개선은 주산지 날씨 · 수입량 · 출하량 같은 새 자료가 필요 |
| 한계 ③ | 설명: 부스팅은 "왜"를 바로 말하기 어려움 → **숫자는 모델, "이렇게 본 이유"는 지금 공식** 으로 같이 보여 줌 |
| 한계 ④ | 야채만 비교. 과일 · 수산물 · 육류는 따로 해야 함 |

## 4. 채택하면 바뀌는 것 (제안)

|---|---|
