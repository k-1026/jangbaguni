| 종류 | 방법 | 정반대 ↓ (목표) | 평균 오차 ↓ (안전장치) | 범위 적중 | 건수 |

| 야채 | 고정 공식 | 28.2% | 19.19%p | 71.1% | 4,496 |

- 목표(정반대 10% 이하)는 아직 못 미침 → "매일 스스로 개선 중"으로 말하기

## 2. 매일 새벽 스스로 교체한 기록 (AI가 실험을 고르고, 기준을 넘을 때만 교체)

교체 기준: 정반대 0.3%p 이상 줄고 **그리고** 평균 오차가 늘지 않을 때

| 날짜 | 종류 | AI가 고른 실험 | 결과 (정반대 · 평균 오차) | 결정 |
|---|---|---|---|---|
| 11/16 | 야채 | 한파 일수 빼기 / 1주 전 대비 넣기 | 23.27% (나빠짐) / 22.82% (−0.27%p, 기준 미달) | 유지 |
| 11/16 | 과일 | 날씨 점수 빼기 / **1주 전 대비 넣기** | 20.23% / **19.68% · 12.94%p** | 🔄 **교체** |
| 11/17 (새벽) | 야채 | 날씨 점수 빼기 / **나무 깊이 4 → 3** | 23.38% / **22.82% · 17.85%p** | 🔄 **교체** (첫 자동 실행) |
| 11/17 (새벽) | 과일 | 한파 일수 빼기 / 요일 넣기 | 20.36% / 20.05% · **오차 12.996%p로 늘어남** | 유지 (안전장치에 걸림) |
| 11/17 (2회차) | 야채 | 반입량 수준 넣기 / 잎 최소 건수 150 → 100 | 23.40% / 23.53% (둘 다 나빠짐) | 유지 |
| 11/17 (2회차) | 과일 | 폭염 일수 빼기 / 반입량 수준 넣기 | 20.23% (−0.24%p, 기준 미달) / 20.26% | 유지 |

- **발표용 한 줄**: "이틀 동안 AI가 실험 8개를 골랐고, 기준을 넘은 2개만 스스로 바꿨다 — 좋아 보여도 기준에 못 미치거나 오차가 늘면 걸러 냈다"
- AI 진단 예시 (11/17 야채, 받은 그대로): "양배추 정반대 30.56%, 상추 29.24%로 높아… 모델 단순화 접근이 필요합니다" → 실제로 "나무 깊이 4 → 3"을 골라 교체됨
- ⚠️ 11/18 새벽 기록은 사이트에서 아직 안 보임 → 11/18 실행이 됐는지 GitHub Actions "매일 새벽 학습"에서 확인 필요

## 3. 직접 만든 부스팅 vs 표준 라이브러리 (11/17)

같은 자료 · 같은 시험 기간(2025-11-10 ~ 2026-11-09) · 같은 지표

| | 야채 정반대 | 야채 평균 오차 | 과일 정반대 | 과일 평균 오차 |
|---|---|---|---|---|
| 고정 공식 | 28.2% | 19.19%p | 21.8% | 14.41%p |
| **우리 부스팅** (`gbdt.py`) | **22.8%** | **17.85%p** | 20.5% | 12.88%p |
| LightGBM (같은 설정) | 23.4% | 18.08%p | 20.5% | 12.92%p |

- **발표용 한 줄**: "직접 구현한 부스팅이 LightGBM · XGBoost와 같은 수준 이상 (야채 정반대 22.8% vs 23.4% · 24.8%)"
