# 예측 방향 맞음 58.5% — 원인과 고칠 방법 실험 (11/25)

> 무엇: 사이트 실전 채점(최근 4주) **방향 맞음 58.5% (217건 중 127건)** 이 낮다 → 왜 그런지, 학습 방법 · 방향 기준을 바꾸면 오르는지 과거 1년 시험(야채 4,481 · 과일 2,906건)으로 확인

> 시험: 2025-11-18 ~ 2026-11-17 (매일 학습과 같은 "최근 1년"), 설정은 매일 학습 기본값 + 야채는 서울 10년 ([학습 기간 실험](1125_train_length_10y.md))

## 1. 방법별 (시험 1년)

| 방법 | 야채 방향 맞음 | 야채 정반대 | 과일 방향 맞음 | 과일 정반대 |
|---|---:|---:|---:|---:|
| 그대로 (늘 비슷) | 9.0% | 0% | 12.6% | 0% |
| 최근 1주 흐름 그대로 | 37.4% | 46.9% | 36.9% | 42.1% |
| 고정 공식 | 44.6% | 28.1% | 34.0% | 21.4% |

| AI 기준 ±1% | 57.3% | 26.5% | 55.6% | 24.3% |

## 2. 다른 학습 방법 (같은 정반대 수준에서 비교)

검증 1년에서 정반대가 지금 AI 이하가 되는 기준을 골라 시험에서 확인

| 학습 방법 | 야채 방향 맞음 · 정반대 | 과일 방향 맞음 · 정반대 |
|---|---|---|
| **지금 (몇 % 변할지, 절대오차)** | **54.0% · 22.7%** | **51.7% · 19.4%** |
| 방향만 배우기 (오를 +1 · 비슷 0 · 내릴 −1) | 52.0% · 23.1% | 50.4% · 19.6% |
| 변화율을 ±5%로 잘라 배우기 | 52.0% · 23.5% | 49.4% · 19.8% |
| 변화율을 ±10%로 잘라 배우기 | 53.3% · 24.1% | 51.3% · 19.4% |

→ 지금 방식이 가장 나음. 앞서 해 본 것(가락 선행 · 산지 날씨 · 완벽한 예보 · 13개 기법 · LightGBM · XGBoost)도 큰 차이가 없었음 → **지금 자료로는 7일 방향의 한계가 55 ~ 60% 근처**

## 3-1. "찍어도 50%"인가

오를 · 비슷 · 내릴 **세 갈래** 채점이라 무작위로 찍으면 **34%**, 늘 "오를"이면 야채 46% · 과일 41% (가장 많은 쪽으로 찍기). AI 54 · 52%는 찍기보다 8 ~ 20%p 위.
실제로 ±2% 넘게 움직인 날만 보면 AI 오를 / 내릴 방향은 **66%** (동전 50%) — 틀리는 몫의 큰 부분이 "비슷" 가르기

## 3-4. ⭐ 맞히는 대상 바꾸기 — "7일 뒤 하루 값" → "다음 주 평균 vs 이번 주 평균"

하루 경락가는 그날 반입량에 따라 크게 출렁임 → 사장님이 장 보는 단위(일주일)의 **평균값**을 맞히면 덜 출렁이고 더 쓸모 있음 ([smooth_target.py](../../salpi_agent/experiments/smooth_target.py))

| | 야채: 지금 → **주 평균** | 과일: 지금 → **주 평균** |
|---|---|---|
| 방향 맞음 (전부) | 54.0 → **56.3%** | 51.7 → 48.8% (실제 비슷이 12.6 → 18.1%로 늘어 세 갈래가 어려워짐) |
| 정반대 | 22.7 → **18.0%** | 19.4 → **13.5%** |
| 평균 오차 | 17.78 → **12.13%p** | 12.82 → **8.07%p** |
| 움직인 날 오를 / 내릴 | 66.3 → **71.0%** | 66.7 → **69.5%** |
| **확신 있을 때만 (예측 4% 이상)** | 66.5 → **70.5%** (예측의 63%) · 정반대 19.2% | 67.8 → **71.5%** (예측의 39%) · 정반대 16.8% |
| 확신 있을 때만 (예측 8% 이상) | 71.6 → **80.0%** (예측의 36%) · 정반대 13.6% | 75.5 → **81.2%** (예측의 16%) · 정반대 12.6% |

→ **70%를 넘기는 길 = 주 평균으로 맞히기 + 4% 넘게 움직일 때만 방향 말하기**. 나머지는 "큰 변화 없을 듯(± 범위)"으로

## 4. 고를 수 있는 길 (팀 결정 필요)

|---|---|---|---|
