# 대체 재료 추천 규칙 (11/25 정함)

> 원가율 40% 이상 메뉴에 나가는 3가지 제안 중 ② 대체 재료의 규칙. 코드는 [receipts.py](../../salpi_agent/store/receipts.py) `SUBSTITUTES` · `_swap`. 이 문서는 팀이 고른 기준을 적은 것이고, 코드는 아직 안 바꿨다.

| # | 질문 | 정한 것 | 코드 상태 |
|---|---|---|---|
| 1 | 닭 부위 대체의 가격 근거 | 컬리 판매가 kg당 비율로 환산하되, 도매 시세와 출처가 다르다는 것을 표시. 신뢰도는 [검증 결과](1125_meat_data_gap.md#3-컬리-가격을-써도-되나--검증) 참고 (비율만 참고용, 값 · 예측은 안 씀) | 안 바뀜. 후보 예측이 없으면 후보를 건너뛰는 분기가 걸림 |
| 2 | 허용 범위 | 같은 종류 안의 다른 부위만 (돼지 → 돼지, 닭 → 닭). 종류를 넘는 대체는 안 함 | 이미 그렇게 돼 있음 |
| 3 | 최소 절감 | 1인분 10원 이상만 추천 | 이미 그렇게 돼 있음 (`saving < 10`) |
| 4 | 바꾸는 비율 | 오른 재료의 50%만 바꿨을 때로 계산 | 이미 그렇게 돼 있음 (`SWAP_SHARE = 0.5`) |
| 5 | 불확실한 추천 표시 | **확인 대기** | — |

## 닭 부위 후보 (제안, 확정 아님)

컬리 표본이 가장 많은 순. 표본이 작아서(6~51개) 부위 사이 비율은 참고용이다.

| 오른 재료 | 후보 |
|---|---|
| 닭 가슴살 | 닭 다리살 · 닭 안심 |
| 닭 다리살 | 닭 가슴살 · 닭 안심 |

## 지금 코드로 닭 대체를 켜려면 바꿀 곳

1. `SUBSTITUTES`에 닭 부위 추가
2. `_wholesale()`이 닭 부위에서는 시세 대신 컬리 비율을 돌려주게 하고, "다음 주 예상" 없이 계산하는 분기 추가
3. 추천에 `price_basis`로 컬리 출처 표시
4. 같은 입력에서 돼지고기 추천이 그대로 나오는지 확인하는 테스트
