## 1. 실험 1 — 서울 안에서 학습 기간만 바꾸기

- 자료: 서울 가락 중도매 '상품' 조사가 (aT 일별 도·소매 = KAMIS), 14품목 · 기준일 32,166줄. 2016 ~ 2019 = `data/raw/1124_veg_past_seoul_daegu/seoul_1101`, 2020 ~ 2025-08 = `data/raw/1112_*.csv.xz`. 2019-12 → 2020-01 품종별 kg당 값이 이어지는 것을 확인
- 요인: 값으로 만든 것만 (서울엔 반입량 · 대구 날씨가 없음) — 품목 · 4주 평균 차이 · 2주 기울기 · 변동성 · 3거래일 · 1주 변화 · 지난 해 같은 때 · 명절까지 남은 날(2016 ~ 2020 설 · 추석 더함) · 월
- 모델 설정: 매일 학습 기본 설정 (부스팅, 나무 수는 학습 자료 마지막 1년으로 고름)

| 학습 기간 | 시험 2023-09 ~ 2024-08 평균 오차 / 정반대 | 시험 2024-09 ~ 2025-08 평균 오차 / 정반대 |
|---|---|---|

## 2-1. 실험 3 — 나빠진 품목(오이 · 청양고추) 줄이기

고르는 일은 **시험 바로 전 1년(검증, 2024-11 ~ 2025-10)** 으로만 하고, 시험 기간(2025-11 ~ 2026-10)은 확인만 함 (시험을 보고 고르면 숫자가 부풀려짐)

| 방법 | 평균 오차 ↓ | 정반대 ↓ | 오이 정반대 | 청양고추 정반대 |
|---|---:|---:|---:|---:|
| 대구만 (지금) | 17.68%p | 23.1% | 20.9% | 18.6% |
| + 서울 (2절) | 17.64%p | 22.2% | 25.9% | 21.9% |
| **+ 서울 + 출처 요인** (서울 / 대구 칸을 더해 두 시장 차이를 따로 배움) | 17.59%p | **22.2%** | 26.2% | 19.6% |
| **두 모델 평균** (대구만 · + 서울 예측을 반반) | **17.58%p** | 22.3% | 22.9% | 20.3% |
| 품목별 고르기 (검증에서 서울이 도움 된 품목만 서울 섞기) | 17.67%p | 22.3% | 21.9% | 21.6% |
| 품목별 고르기 + 출처 요인 | 17.77%p | 22.2% | 22.3% | 20.9% |

- **전체 성적은 방법끼리 거의 같음** (정반대 22.2 ~ 22.3%, 모두 대구만보다 0.8 ~ 0.9%p 나음)
- **나빠진 품목을 완전히 되돌리는 방법은 없음.** 오이는 "두 모델 평균"이 25.9 → 22.9%로 가장 많이 줄이고, 청양고추는 "출처 요인"이 21.9 → 19.6%로 가장 많이 줄임. 둘 다 대구만(20.9 · 18.6%)보다는 여전히 1 ~ 2%p 높음
- **품목별 고르기는 안 맞음**: 검증 1년에서 서울이 도움 된다고 고른 품목에 청양고추가 들어갔는데 시험에서는 나빠짐. 품목 하나 · 1년(약 300건)으로는 운이 섞임 — [13개 기법 매칭](1116_self_learning_forecast.md)에서 본 것과 같은 결론
- 이 한 해만 보면 "두 모델 평균"이 나아 보였지만, 세 해를 모두 보면 **"출처 요인"이 가장 꾸준함** (2-2절)

## 2-2. 실험 4 — 시험 해를 바꿔 세 번 (대구 자료가 2021-01부터라 2023-11 시험이 가장 이른 해)

평균 오차 %p / 정반대 % (괄호: 오이 · 청양고추 정반대 %)

| 방법 | 시험 2023-11 ~ 2024-10 | 시험 2024-11 ~ 2025-10 | 시험 2025-11 ~ 2026-10 | **세 해 평균** |
|---|---|---|---|---|
| 대구만 (지금) | 19.68 / 27.3% (33.5 · 25.3) | 18.21 / 25.4% (22.9 · 29.1) | 17.68 / 23.1% (20.9 · 18.6) | 18.52 / 25.3% |
| + 서울 | 19.42 / 26.4% (30.6 · 28.0) | 18.05 / 24.9% (22.9 · 27.5) | 17.64 / 22.2% (25.9 · 21.9) | 18.37 / 24.5% |
| **+ 서울 + 출처 요인** | 19.47 / **26.1%** (28.9 · 27.0) | **18.00 / 24.6%** (23.2 · 27.5) | 17.59 / **22.2%** (26.2 · 19.6) | **18.35 / 24.3%** |
| 두 모델 평균 | 19.46 / 26.9% (30.6 · 27.6) | 18.03 / 24.9% (22.2 · 28.8) | **17.58** / 22.3% (22.9 · 20.3) | 18.36 / 24.7% |

- **세 해 모두 서울 10년을 섞는 쪽이 나음** — 평균 오차 · 정반대 둘 다. 한 해 운이 아님
- **"+ 서울 + 출처 요인"이 세 해 모두 정반대가 가장 낮음** (대구만보다 −1.2 · −0.8 · −0.9%p), 평균 오차도 세 해 모두 대구만보다 낮음 → **세 해 모두 매일 학습 교체 기준 통과**
- **오이 · 청양고추는 해마다 엇갈림**: 오이는 2023 ~ 24에 33.5 → 28.9%로 오히려 크게 좋아졌고 2025 ~ 26에만 나빠짐. 청양고추는 세 해 중 두 해 나빠짐 (25.3 → 27.0 · 18.6 → 19.6), 한 해 좋아짐 (29.1 → 27.5) → 품목 하나 · 1년의 차이는 대부분 흔들림. 품목별로 따로 처리하지 않고 전체로 판단하는 게 맞음
- **추천: "+ 서울 + 출처 요인"** — 지금 학습 방식에 서울 줄과 "서울 / 대구" 칸 하나만 더하면 됨. 화면 예측은 늘 대구(0)로 함

## 3. 읽는 법 · 한계 · 다음

- **발표에 쓸 말**: "대구 자료가 4년뿐이라 서울 10년 치를 더해 학습해 봤더니, 방향을 거꾸로 맞히는 비율이 23.1 → 22.2%로 줄고 평균 오차는 늘지 않았다"
- 한계
  - 씨앗만 바꿔도 정반대가 ±0.3%p 흔들림 → 방법끼리 차이(출처 요인 vs 두 모델 평균 0.1 ~ 0.4%p)는 그 안쪽. "서울을 섞으면 낫다"는 세 해 모두 0.8 ~ 1.2%p라 그보다 큼
  - 서울은 조사가(KAMIS), 대구는 정산 경락가라 값의 성격이 다름. 오이 · 청양고추처럼 오히려 나빠진 품목이 있음
  - 서울 자료가 2025-08에서 끝남 → 서비스에 넣으면 최근 1년 남짓은 대구만 있음 (가락 최근 자료 `1124_garak_veg_recent`를 이어 붙일 수 있음)
  - 실험은 매일 학습 **기본 설정**으로 돌림. 오늘 챔피언 설정(나무 깊이 3 등)과는 조금 다를 수 있음
