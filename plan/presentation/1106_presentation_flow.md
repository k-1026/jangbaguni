### 발표 메시지: "식재료비 1%만 아껴도 구독료의 6배가 남는다" (예시 계산)
- 근거 숫자: 일반음식점 식재료비 비중 **40.7%**, 영업이익률 **8.7%** (KREI, 11/4 발표 3번 슬라이드)
- 가정: 월 매출 3,000만 원 식당 · 구독료 월 19,900원
  - 식재료비 ≈ 1,221만 원 → 1%만 아껴도 **월 약 12만 원** → 구독료의 **약 6배**
  - 영업이익(≈ 261만 원)이 약 4.7% 늘어나는 효과
- 발표 화면에 **"예시 계산 · 가정값"** 표시 필수. 실제 절감 효과는 시범 운영 뒤에 말할 것

## 5. 해야 할 것

### ① 로그인 · 로그아웃
- 지금: 로그인 기능 없음. 시연 기본 계정으로 "로그인했다고 치고" 나의 가게를 보여 줌 (`salpi_agent/web/app.js` 의 `SIGNED_IN`)
- 할 일: 카카오 로그인 → 사장님별 가게 · 판매 기록 · 영수증을 나눠 저장 (Supabase에 사용자별 가게 연결) → 마이페이지 로그아웃 · 회원탈퇴 버튼 연결
- 결정할 것: 카카오만 할지 · 무료 범위 안에서 될지

### ② 예측 방식: 지금은 "추론(계산)", 학습 모델은 고안 단계
- **지금 시세 예측** (`analysis.py`): 학습 모델이 아니라 이유를 하나씩 더하는 **규칙 계산**
  - 최근 2주 흐름(절반만 반영) + 도매시장 반입량 + 대구 날씨 + 다가오는 공휴일 + 대구 행사 → 다음 7일 변화 % 와 범위
  - 장점: 이유를 그대로 보여 줄 수 있음 ("반입량이 줄어 +3%")
- **지금 판매량 예측** (`demand.py`): 최근 4주 평균 + 요일 차이 + 최근 흐름(절반) + 공휴일, 범위는 지난 4주 오차로
- **제미나이(무료)의 역할**: 숫자를 만들지 않음. 위 계산 결과를 도구로 불러와 살피 말투로 설명만 함
- **학습 모델 고안 (안)**
  - 데이터: 대구 도매 경락가 · 반입량 시계열 + 날씨 + 공휴일 · 행사 (지금 쓰는 것과 같은 데이터)
  - 방법 후보: 과거 1~2년으로 품목별 회귀 · 부스팅 모델을 학습해 7일 뒤 가격 범위를 예측
  - 비용 0원 유지: 학습은 내 컴퓨터나 GitHub Actions에서 주 1회, 사이트는 결과만 읽음
  - 비교: 지난 기간으로 "지금 규칙 계산 vs 학습 모델" 오차를 비교해 나은 쪽 사용 (이유 설명은 규칙 계산 쪽을 함께 보여 줌)
- 발표에서는 "지금은 근거를 보여 주는 계산, 데이터가 쌓이면 학습 모델로"라고 단계로 말하기

### ③ 그 밖에
- 시범 운영 사장님 1~2명 → 실제 절감액으로 ROI 슬라이드 업데이트
- DART 사업보고서 원문 확인 (기업 리서치 `[U]` 칸)
