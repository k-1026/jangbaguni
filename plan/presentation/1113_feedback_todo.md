## 4. 새로 넣을 시세 자료 2가지 (11/13 추가)

### 4-1. 서울 가락시장 경락가: "가락이 먼저 움직이나" (B-9)

**왜**
- 가락시장은 전국 물량이 모이는 가장 큰 시장 → 대구 북부도매보다 **값이 먼저 움직일 가능성**
- 지금 화면의 예측 이유는 "4주 평균보다 비싸요"처럼 대구 숫자뿐. "서울에서 먼저 오르고 있다"는 이유가 붙으면 **사장님이 예측을 믿을 근거**가 됨
  - 화면 문구 예: "서울 가락시장에서 사과값이 3일째 오르고 있어요. 대구도 곧 따라 오를 수 있어요."

**어떻게 받나**
- 지금 대구 경락가를 받는 **aT 정산정보 API(`katSale/trades`)에서 시장 코드만 바꾸면 됨**
  - 지금: `cond[whsl_mrkt_cd::EQ]` = `220001` (대구 북부도매, `data_sources.py` `DAEGU_MARKET`)
  - 가락: 서울가락도매 시장 코드 (`110001`로 알고 있음 → **API 응답으로 확인 후 사용**)
- 5년 치(2021-01 ~ 지금)를 받아 `data/raw/` 에 저장. 받는 코드는 `data/raw/1109_5y/scripts/fetch_price_wholesale.mjs` 를 시장 코드만 바꿔 재사용
- ⚠️ 가락은 하루 거래 건수가 대구보다 훨씬 많아 **페이지(1,000건) 수가 크게 늘어남** → 하루 호출 한도(공공데이터포털) 안에서 며칠에 나눠 받기. 품목 조건(`gds_mclsf_nm` 등)으로 우리 품목만 걸러 받을 수 있는지 먼저 확인

**채점 기준으로 추가 (새 항목)**

| 채점 항목 | 무엇을 보나 | 통과 기준 (안) |
|---|---|---|
| **가락 선행 적중률** | 가락이 N일(1·3·5일) 연속 또는 ±X% 올랐을 때(내렸을 때), **k일(1~7일) 뒤 대구도 같은 방향**으로 움직였나 | 같은 방향 비율이 "아무 날이나 골랐을 때"보다 뚜렷이 높음 |
| 가장 잘 맞는 시차 | 품목마다 가락 → 대구가 며칠 뒤에 따라오나 (교차 상관) | 품목별 시차 표 |
| 넣었을 때 효과 | 지금 공식 + "가락 흐름" 이유를 넣고 다시 채점 | **정반대가 줄고 방향 적중률이 오를 때만** 공식에 넣음 (넣어서 나빠지면 육류 경락가처럼 뺌) |

- 채점은 `backtest.py` 에 갈래로 추가 (예전 · 지금 공식과 나란히), 결과는 품목별로 (과일 · 야채가 다르게 나올 수 있음)
- 공식에 넣지 않더라도 **선행 적중률이 높은 품목은 화면의 "이유"로만** 보여 주는 것도 가능
