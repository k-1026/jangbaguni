## 2. 장별 근거 보충

### 1장 문제 — "정말 있는 문제인가?"

**메시지 하나**: 사장님은 "언제 살까"보다 **"메뉴 하나 팔면 얼마 남나"**를 모른다

| 넣을 근거 | 값 | 출처 | 등급 |
|---|---|---|---|
| 원가 계산이 어렵다 | 333장 중 195장 (59%) | [VOC 분석](../bm/1112_voc_analysis.md) 2절 | 팀 조사 |
| 재료값이 계속 오른다 | 179장 (54%) | 같은 곳 | 팀 조사 |
| 남는 게 없다 | 133장 (40%) | 같은 곳 | 팀 조사 |
| "언제 사야 할지" (처음 가정 1순위) | **7%뿐** → 문제 정의를 바꾼 근거 | 같은 곳 3절 | 팀 조사 |
| 외식업 식재료비 비중 | 40.7% (2024 실적) | 농식품부 외식업 경영실태조사 | A |
| 외식업 영업이익률 | 8.7% → 식재료비 1%만 아껴도 영업이익의 약 4.7% | 같은 곳 + 뉴시스 | A |
| 시세 급등락 예 | 양배추 포기당 1,276원 → 2,140원 (+67.7%) | [밸류체인 분석](../../research/company/cj_freshway/valuechain/analysis.md) B1 | 출처 43 |

- **대표 목소리 1개만** 크게: "몇 달 전과 같은 걸 사는데 영수증 금액이 확 달라졌어요" 또는 "고기 600g 원가 5,280원, 이 계산 맞나요?"
- **약한 곳**: 원가 낱말로 검색해서 모은 글이라 원가 비율이 높게 나오는 건 당연한 면이 있음 → 발표에서는 "비율"보다 **"순서가 뒤집혔다(7% vs 59%)"**를 강조. 사장님 5명 직접 확인(R14)이 오면 "카페 333장 + 직접 5명" 두 근거로
- **이 장에서 빼기**: 인건비 · 임대료 · 배달 수수료(27 · 23 · 20%) — 살피가 푸는 문제가 아니므로 메시지를 흐림

### 2장 해결 — "왜 이 방법인가?" (AI가 어디에 어떻게 쓰이나)

**메시지 하나**: 영수증 사진 한 장이면, 원가율 계산부터 다음 행동 제안까지 AI가 대신한다

**As-Is → To-Be (초안, 슬라이드용)**

| 단계 | As-Is (지금 사장님) | To-Be (살피) | AI가 하는 일 |
|---|---|---|---|
| 기록 | 영수증 · 메모를 손으로 옮겨 적거나 엑셀 | 영수증 **사진 · PDF 한 장** | 🤖 사진 → 품목 · 양 · 금액 읽기 → 기준 단위(kg · L · 개)로 환산 |
| 계산 | 재료값이 바뀔 때마다 **손으로 다시 계산** | 메뉴별 원가율이 **자동으로 다시 계산** | ⚙️ 레시피(g) × 단가 계산 (숫자는 계산으로만) |
| 판단 | "옆집도 올렸으니 500원" (감) | 원가율 40% 넘으면 **가격 조정 · 대체 재료 · 메뉴 제안** 3가지 | ⚙️ 계산 + 🤖 살피 말투로 설명 |
| 미리 보기 | 오르고 나서야 앎 | **다음 7일 시세 예측** + "이렇게 본 이유" | ⚙️ 매일 새벽 스스로 다시 배우는 학습 모델 + 🤖 실험 고르기 |
| 구매 | 늘 사던 거래처 | 산 값이 시세보다 싼지 · 더 싼 곳 | ⚙️ 단위 환산 + 판매처 가격 비교 |

- **핵심 한 줄**: "AI는 읽고 · 나누고 · 실험을 고르고 · 말한다. **숫자는 계산과 학습 모델이 만든다**(AI가 숫자를 지어내지 않음)" — 질문이 들어왔을 때 신뢰를 지키는 답
- **약한 곳**
  - 발표 그림은 "담당별 서브에이전트"인데 코드는 아직 한 덩어리 ([최종 계획](../1116_final_sprint_plan.md) 3절 #4) → **A1~A5 나누기 + V7 전후 비교표**(걸린 시간 · AI 호출 수 · 맞는 담당)가 있어야 그림이 근거가 됨
  - 평가표의 **spec.md 없음**(D5, 11/27 예정) → 최소한 위 표 + 기능 목록 1장이라도 먼저
- **이 장에서 빼기**: 모델 성적 숫자(→ 5장), 수익 구조(→ 4장)

### 3장 시장 — "충분히 큰가?"

**메시지 하나**: 원가 도구와 시세 도구 사이의 **빈 자리**를 살피가 차지한다 (숫자는 그 자리의 크기)

| 넣을 근거 | 값 | 출처 | 등급 |
|---|---|---|---|
| 포지셔닝 | 살피 9.0 / 8.0 (오른쪽 위 혼자), 가장 가까운 원까 6.0 / 0.0 | [포지셔닝 맵](../bm/1113_포지셔닝맵.md) | 팀 채점 (기능 근거 A) |
| 경쟁 도구에 없는 기능 | 예측 채점 공개 0곳 · 대구 시세 0.5곳 · 다음 행동 제안 0.5곳 | [경쟁사 비교](../bm/1113_경쟁사비교.md) | App Store · 웹 원문 |
| TAM | 788,862곳 × 연 238,800원 = **약 1,884억 원** | aT FIS (서비스업조사) | A |
| SAM | 대구 한식음식점 19,156곳 → **약 46억 원** | 브랜드키트 기획서 인용 | **C (출처 불명)** |
| SOM 3년차 | SAM의 3% = 575곳 | 팀 가정 | C |

- **가장 급한 보충**: 19,156곳 → **KOSIS 전국사업체조사**(대구광역시 × "한식 일반 음식점업") 또는 **LOCALDATA 일반음식점 인허가**(대구, 영업 상태 "영업 중", 업태 "한식")로 바꾸고 연도 표기. 숫자가 바뀌면 SAM · SOM을 시트에서 다시 계산 (노란 칸만 바꾸면 됨)
- **주의**: TAM 788,862곳은 주점 · 카페 포함 → 슬라이드에 "음식점 및 주점업" 그대로 적기. 원까가 시세 연동을 붙이면 빈 자리가 사라질 수 있음 → "버팀목은 대구 경락가 예측 + 채점 공개"를 준비된 답으로
- **한 장 한 메시지 주의**: 경쟁 비교표(12칸) + 포지셔닝 맵 + TAM/SAM/SOM을 한 장에 다 넣으면 메시지가 셋. **본 장에는 포지셔닝 맵 + SOM 한 줄**, 비교표 · TAM 계산은 부록으로

### 4장 BM — "지속 가능한가?"

**메시지 하나**: **구독 하나로도** 남는 구조이고, 성패는 **해지율**에 달려 있다

**⚠️ 꼭 고칠 것: 제휴 수수료를 빼면 숫자가 바뀜**

시장 규모 시트의 객단가 28,900원에는 불확실한 제휴 수수료 9,000원이 들어 있음 (TAM · SAM은 이미 구독만, **SOM과 단위 경제만** 제휴 포함). 구독만으로 다시 계산하면:

| 항목 | 지금 (구독 + 제휴) | 구독만 | 계산 |
|---|---|---|---|
| 객단가 | 28,900원 | **19,900원** | |
| 월 변동비 | 2,594원 | 약 2,297원 | AI 900 + 알림톡 240 + 서버 500 + 결제 3.3%(657) |
| 공헌이익 | 26,306원 | 약 17,603원 (88%) | |
| LTV (해지율 5%, 20개월) | 526,126원 | 약 352,000원 | |
| CAC | 133,333원 | 133,333원 | 그대로 |
| **LTV ÷ CAC** | 3.9배 | **약 2.6배** | 3배 기준 아래로 |
| CAC 회수 기간 | 5.1개월 | 약 7.6개월 | 12개월 안이라 여전히 괜찮음 |
| SOM 3년차 매출 | 약 2.0억 원 | **약 1.37억 원** | 575곳 × 19,900원 × 12 |

- **3배를 넘기려면 (시나리오)**: ① 월 해지율 **4.4% 이하** (LTV 40만 원 이상) 또는 ② 무료 → 유료 전환율 **15% → 17% 이상** (CAC 11.7만 원 이하) 또는 ③ 제휴 수수료를 "덤"으로 더하면 3.9배
- **발표에서 이렇게 말하기**: "구독만으로 LTV÷CAC 2.6배, 회수 7.6개월. 해지율을 4%대로 지키거나 제휴가 붙으면 3배를 넘는다" → 숫자를 부풀리지 않고, **민감도 1위 가정(해지율)**으로 7장 요청사항과 이어짐
- **보충**: 구독료 19,900원 근거 = 경쟁 앱 키친코스트 Pro 19,900원(레시피 원가만, App Store A) + 아끼는 돈 4.4배 + **사장님 지불 의향 4문항(R14, ⬜)**. 지불 의향이 없으면 "왜 19,900원?"에 막힘
- **한 장 한 메시지 주의**: BM 캔버스 9칸은 부록, 본 장에는 **"돈의 흐름 그림 + 단위 경제 3숫자(객단가 · LTV÷CAC · 회수 기간)"**만

### 5장 MVP — "보여 줄 수 있나?" (실제로 **구현**됐나)
