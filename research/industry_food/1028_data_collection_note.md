## 5. 키 · 방문이 필요한 데이터

**aT 도매시장 API (data.go.kr, 무료 · 자동승인, 개발계정 10,000건/일)**
- 실시간 경매정보: https://www.data.go.kr/data/15141808/openapi.do (`/B552845/katRealTime2/trades2`)
- 정산정보(일별 최저/최고/평균가): https://www.data.go.kr/data/15141809/openapi.do (`/B552845/katSale/trades`)
- 표준코드(품목 소분류 매핑용): https://www.data.go.kr/data/15141818/openapi.do
- 하루 단위 조회라 5년 백필은 오래 걸림 → **학습은 KAMIS 5년치, aT API는 매일 자동 수집(STEP 1)용**

**기상청 ASOS 일자료**: data.go.kr 활용신청 또는 https://data.kma.go.kr — 대구 지점 `143`, 공식 발표용은 이걸로 교체 권장

**대구 빅데이터활용센터 (대구로 주문 2022~2023, 삼성카드 2024)**
- 폐쇄망 분석실에서 분석 → 결과물만 심사 후 반출. 절차: 대구ID 앱 이용신청 → 분석 → 반출신청서 → 심사 → 반출
- 평일 09:00~18:00, 수성구 알파시티1로 160 SW융합테크비즈센터 2층, 053-215-4955
- 신청: https://data.daegu.go.kr/open/bigData/application.do
- 데이터셋 목록: https://data.daegu.go.kr/open/bigData/dataSetStatus.do
- 반출 목표(미리 정해 가기): 분식 요일×시간대 주문지수(구 · 군별) · 평일/주말 매출 비율 · 월별 매출 지수
