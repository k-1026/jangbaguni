# 주제 발표 정리 (10/28)

근거 · 출처 URL: `industry_food/1028_wholesale_price_forecast_note.md`

---

## 1. 주제명

**대구 도매시장 시세 예측으로 분식집 사장님의 "언제, 얼마나 살지"를 알려 주는 발주 도우미**

- 한 줄 요약: 떡볶이 재료(대파 · 양배추 · 고춧가루)의 도매 시세를 1~2주 앞까지 예측해 구매 시점과 발주량을 제안
- 사용자: 대구 식당 · 분식집 사장님

---

## 2. 선정 이유

1. **지역 명분**: 대구농수산물도매시장은 전국 공영도매시장 거래 규모 3위(2024년 1조 1,217억 원). 하빈면 이전(2032년)과 온라인도매시장 전환이 진행 중
2. **데이터가 좋음**: 품목 · 거래량 · 가격이 매일 쌓이는 시계열이고, 공공 API로 무료 · 실시간 제공
3. **스토리가 있음**: 대구 떡볶이 페스티벌 관람객 33만 명(2025년) → 떡볶이 재료로 범위를 좁히면 대구다운 이야기가 됨

---

## 3. 페인포인트

| 누가 | 무엇이 문제 | 근거 |
|---|---|---|
| 분식집 사장님 | 채소 값이 몇 주 만에 수십 % 오르내려 원가를 예측할 수 없음 | 양배추 3주 만에 +67.7%(2026년 7월), 대파 1주일 새 -27.8%(2025년 4월) |
| 분식집 사장님 | 매출의 40%가 재료비라 비쌀 때 사면 바로 손해 | 일반음식점 식재료비 비중 40.7%, 영업이익률 8.7%(2024년) |
| 분식집 사장님 | 시세 정보는 있지만 "지금 살지, 기다릴지" 알려 주는 곳이 없음 | 식봄 등은 현재 가격 비교만, 도매 시세 앱은 출하자 · 유통인 대상 |

**핵심 문장**: 시세는 공개돼 있지만, 사장님이 쓸 수 있는 "판단"으로 바뀌어 있지 않다.

---

## 4. 사용할 데이터

| 데이터 | 용도 |
|---|---|
| aT 전국 공영도매시장 실시간 경매정보 API | 대구 시장 대파 · 양배추 · 건고추 일별 경락가 · 물량 (예측의 주 데이터) |
| 농식품부 도매시장 정산 가격 API | 정산 가격 · 거래량 보조 |
| KAMIS 일별 도 · 소매 가격 | 고춧가루 소매가, 도매가와 소매가 차이 |
| 기상청 날씨 데이터 (추가 예정) | 장마 · 폭염 등 가격 급변 원인을 예측 변수로 사용 |
| 소상공인 상가(상권)정보 | 대구 분식집 수 → 잠재 사용자 규모 |

---

## 5. 해결 방법 (서비스 흐름)

```
도매 시세 수집 → 1~2주 가격 예측 → 구매 신호(지금 사기 / 기다리기) → 적정 발주량 제안
```

- **가격 예측**: 품목별 시계열 모델로 시작하고, 날씨 변수를 추가해 정확도를 높임
- **구매 신호**: 예측 가격이 오를 것 같으면 "이번 주에 미리", 내릴 것 같으면 "필요한 만큼만"
- **발주량**: 가게의 하루 사용량과 남은 재고를 입력하면 며칠치를 살지 계산

---

## 6. 구체화 단계

| 단계 | 할 일 | 결과물 |
|---|---|---|
| 1. 데이터 | API 키 신청, 대구 시장 3개 품목 일별 가격 수집 | 가격 시계열 CSV + 그래프 |
| 2. 예측 | 기본 시계열 모델 → 날씨 변수 추가, 실제 가격과 오차 비교 | 품목별 예측 그래프 |
| 3. 사용자 확인 | 분식집 사장님 인터뷰 · 설문 (어디서 · 얼마나 · 얼마마다 사는지) | 페르소나 · 하루 사용량 |
| 4. 프로토타입 | "이번 주 장보기 알림" 화면 (구매 신호 + 발주량) | 화면 시안 / 데모 |

---

## 7. 차별점

- 지금 가격 비교(식봄)가 아니라 **앞으로의 가격 + 구매 시점** 제안
- 도매 시세를 **출하자 · 유통인이 아닌 식당 사장님** 쪽으로 연결
- **대구 시장 · 떡볶이 재료**에 집중해 작게 시작하고 다른 메뉴 · 지역으로 확장 가능

---

## 8. 남은 과제

- 고춧가루: 도매시장에서는 "건고추"로 거래 → 건고추 시세로 대신할지 결정
- 사장님이 실제로 어디서 사는지(중도매인 · 식자재마트 · 식봄) 확인 필요
- 떡볶이 1인분 재료 원가는 공개 자료가 없어 직접 계산

---

## 1분 발표 멘트

> 대구농수산물도매시장은 전국에서 세 번째로 큰 공영도매시장입니다. 이 시장의 시세는 매일 공개되지만, 정작 식당 사장님에게는 "지금 사야 할지, 기다려야 할지"라는 판단으로 전달되지 않습니다.
> 실제로 양배추는 올여름 3주 만에 67% 올랐고, 음식점 매출의 40%가 재료비입니다. 비쌀 때 사면 그대로 손해입니다.
> 저희는 대구 떡볶이 재료인 대파, 양배추, 고춧가루로 범위를 좁혀, 도매 시세를 1~2주 앞까지 예측하고 구매 시점과 발주량을 알려 주는 서비스를 만들겠습니다.
> 데이터는 aT 실시간 경매정보와 농식품부 정산가격 공공 API를 쓰고, 날씨 데이터로 급등락을 잡겠습니다. 먼저 가격 예측 그래프를 만들고, 사장님 인터뷰로 사용량을 확인한 뒤, "이번 주 장보기 알림" 프로토타입까지 가는 것이 목표입니다.
