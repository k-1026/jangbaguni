# 살피 · 대구 야채 시세 웹 + AI 에이전트

웹페이지를 열면 첫 화면(초록 영역)에 **야채 시세 대시보드**(날짜별 시세 · 날씨 · 공휴일 · 대구 행사 반영)가 있고,
옆으로 넘기면 **다음 주 오를 가능성이 있는 재료 카드**가 나옵니다. 아래에는 **식봄에서 실제로 파는 상품과 가격**이 있고
(누르면 식봄 상품 페이지로 이동), 오른쪽 아래 **살피 캐릭터**를 누르면 AI 채팅창이 열립니다. 대화는 구글 제미나이 무료 API를 씁니다.

## 처음 한 번 준비
1. 저장소 맨 위 `.env` 에 키 넣기 (견본: `.env.example`)
   - 공공데이터포털 키 (정산정보 · 일별 도·소매가 · 기상청 · 특일 · 관광공사 · 한국소비자원 생필품 가격)
   - `GEMINI_API_KEY` — https://aistudio.google.com → Get API key (무료)
   - `SUPABASE_URL` · `SUPABASE_SECRET_KEY` — 판매량 예측(우리 가게 내일 준비)용. supabase.com → Project Settings → API Keys 의 Secret keys
2. 이 폴더에서 설치
   ```
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

## 실행
- `실행.bat` 더블클릭 → 브라우저에서 http://localhost:8000 이 열림
- 또는 `.venv\Scripts\python server.py`
- 주소 끝에 `#chat` 을 붙이면 채팅창이 열린 채로, `#rise` 를 붙이면 첫 야채 대시보드부터, `#talk` 을 붙이면 알림톡 시연이 열린 채로, `#sea` · `#meat` 를 붙이면 수산물 · 육류 탭이, `#my` 는 마이페이지가, `#settings` 는 마이페이지 › 설정(알림 · 권한)이 열린 채로 시작 (시연용)

처음 켤 때는 4주치 시세를 받느라 **2~3분** 걸립니다. 그다음부터는 `cache/` 에 저장된 값을 써서 빠릅니다.

## 화면
| 부분 | 내용 |
|---|---|
| 맨 위 | 살피 로고 · 메뉴 · 검색 · 기준일 · 알림톡 시연 버튼 (세그먼트별 메시지를 보여 줌, 실제 발송 없음) |
| 검색 | 글자가 이름 어디에 있든 재료(야채 · 수산물 · 육류)와 식봄 상품을 찾음 ("토" → 토마토, 방울토마토 상품). "소고기" → 한우 등심처럼 흔히 쓰는 말도 찾음 (`app.js` 의 `SEARCH_WORDS`). 재료는 재료 전용 페이지로, 상품은 식봄 페이지로 이동 |
| 재료 전용 페이지 (`/?item=토마토`) | 그 재료의 대시보드(4주 그래프 · 예측), 시세판(최근 10거래일 직전 거래일 대비 증감 막대, 등락액 원 · 등락률 % 전환, 상승/하락한 날), 다음 7일 예측과 이유, 구매 바로가기 버튼, 식봄 상품(받아 왔을 때만). 수산물 · 육류(`/?item=돼지고기 삼겹살`)도 같은 구성. 한우 등심 · 양지 · 돼지 앞다리 · 삼겹살은 **등급별 도매 경락가 표**(협신식품, 등급별 가격 · 물량 막대 + "소매가는 경락가의 몇 배")가 시세판 위에 따로 나옴 (대시보드에는 없음) |
| 첫 화면 왼쪽 | 오른 · 내린 · 다음 주 오를 야채 수, 가장 많이 오른 야채 |
| 첫 화면 가운데 | 위쪽 **농산물 · 수산물 · 육류 탭**, 셋 다 같은 대시보드 슬라이드. 농산물: 1장 전체 야채(1주 변화 막대) → 2장부터 야채별(4주 그래프 · 강수량 · 행사 · 공휴일 · 7일 예측 범위 + 아래에 오를/유지/떨어질 예측 문구와 근거), 오를 가능성 높은 순. 수산물 · 육류: 1장 전체 비교 막대 → 2장부터 품목별(4주 그래프 · 7일 예측 범위 · 비(수산물만) · 행사 · 공휴일 · 오를/유지/떨어질 문구, 한우는 100g당 값도), 오를 가능성 높은 순. 화살표는 끝에서 처음으로 돌아감 |
| 첫 화면 오른쪽 | 좌우반전한 살피가 지시봉으로 대시보드를 가리킴 |
| 오늘의 야채 | 식봄 실제 상품 · 할인가 · kg당 가격 (재료별 필터). 누르면 식봄 상품 페이지 |
| 마이페이지 (오른쪽 위 사장님 얼굴) | 프로필 · 내 정보(지역 · 업종, 나의 가게 · 나의 영수증 바로가기) · **설정**(누르면 알림 설정 · 권한 설정) · 로그아웃 · 회원탈퇴 |
| 나의 가게 (`/?page=store`) | 맨 위 **나의 가게** 버튼(알림 왼쪽). 사장님 로그인 시에만 보이는 페이지: 우리 가게 내일 준비 · 영수증 분석 · 메뉴별 원가율. 로그인은 아직 없어서 시연에서는 기본 계정으로 로그인한 것으로 봄 (`app.js` 의 `SIGNED_IN`) |
| 대형마트 판매가 | 한국소비자원 참가격 중 음식 재료(장 · 양념 · 식용유 · 면 · 쌀 · 유제품 · 고기 · 수산 · 가공 · 채소)만. 재료마다 가장 싸게 파는 회사 · 보통 가격 · 대구 매장 값 · 2주 전 대비, 회사별 가격(펼치기). 종류별 필터, 2주 새 오른 재료부터 |
| 시세에 영향을 주는 것들 | 대구 7일 날씨 · 30일 안 공휴일 · 14일 안 대구 행사 |
| 살피 챗봇 (오른쪽 아래) | 살피 캐릭터를 누르면 채팅, 끌면 원하는 곳으로 이동(놓은 자리는 브라우저가 기억). 채팅창 가장자리·모서리를 끌어 크기 조절(마우스를 대면 화살표 커서). 누르기만 하면 되는 질문 3개 |

### 살피 챗봇 기본 질문
1. **야채값 시세변동 추이 말해줘.** → 많이 오른·내린 야채와 지금 사기 좋은 야채 추천
2. **이 가격에 팔아도 남아?** → "어떤 메뉴를 만드시는지 알려주세요" → 메뉴 · 판매가를 들으면 1인분 재료비 · 원가율 · 남는 돈 계산
   (표준 레시피: 김치찌개 · 제육볶음 · 된장찌개 · 떡볶이 · 비빔밥 · 부대찌개 · 오징어볶음, 그 밖의 메뉴는 재료와 양을 말하면 계산)
3. **지금 사면 이득인 야채 알려줘** → 미리 살 것 · 지금 싼 것 · 기다릴 것

## 알아 둘 점
- 예측은 학습 모델이 아니라 **이유를 하나씩 보여 주는 규칙 기반 추정**입니다
  (최근 2주 흐름 · 반입량 · 대구 날씨 · 공휴일 · 대구 행사). 주산지 날씨와 수입량은 아직 반영하지 않았습니다.
- 메뉴 원가의 채소값은 **도매 경락가**라 실제 구매가보다 낮게 나올 수 있고, 양념 · 두부 등은 **시연용 참고 단가**입니다.
- **육류 · 수산물**은 `data_sources.EXTRA_ITEMS`에 따로 있습니다 (농산물 `ITEMS`와 섞지 않음).
  - 육류 7개: 한우 등심 · 양지(1등급), 수입 소고기 갈비살(미국산), 돼지고기 앞다리 · 삼겹살, 닭고기, 계란(30구 일반란) — **대구 소매 평균**
    - KAMIS에는 육류 도매가가 없고(대구 · 전국 모두 소매만), 도매는 경매 경락가뿐입니다. 사장님이 실제로 사는 값이 중요해서 **대시보드 · 예측은 소매가** 기준입니다.
    - 협신식품(대구) 도매 경락가(축산물품질평가원 축산물경락가격정보, `.env` 의 `EKAPE_API_KEY`)는 **예측 이유**와 **재료 페이지 등급표**에만 씁니다.
  - 수산물 12개: 오징어 · 고등어 · 갈치 · 명태 · 굴 · 홍합 · 새우 · 마른멸치 · 김 · 마른미역 — **북부도매시장 중도매가**, 새우젓 · 멸치액젓 — **대구 소매 평균**
  - 대구 북부도매시장 경매(정산정보)에는 없어서 aT 일별 도·소매가(KAMIS 조사)를 씁니다. 반입량이 없어 7일 예측(`analysis.extra_forecast`)은
    **최근 2주 흐름 · 한 달 평균과의 차이(되돌림) · 명절(고기 · 차례 생선) · 김장철(젓갈 · 굴) · 대구 행사(고기)** 로 추정합니다.
    마른 수산물은 조사가 드물어 0.0%가 자주 나옵니다.
  - 메뉴 원가 계산에서는 이 값이 참고 단가 대신 쓰입니다 (값을 못 받은 날은 참고 단가).
  - 품목을 늘리려면 perDay에 `ctgry_cd`(500 축산 · 600 수산)와 `item_cd`를 함께 넣어 대구 응답을 확인한 뒤 추가합니다
    (품목 코드 없이 분류만 넣으면 0건이 나옴). 등급이 여러 개면 `grd`로 하나만 골라야 등급이 빠진 날 값이 튀지 않습니다.
  - 화면: 시세 대시보드 위 **농산물 · 수산물 · 육류 탭**. API: `/api/meat-seafood`, 챗봇 도구: `get_meat_seafood_prices`
  - 경락가: 한우는 같은 부위 1등급(`beefGrade`, 부위 경매가 없는 날은 빔), 돼지는 부위 경매가 없어 도체(`pigGrade`, 등외 제외 평균).
    예측 이유에 **도매 경락가 흐름**(경락가가 1주 새 소매가보다 더 움직인 만큼의 30%, 최대 ±4%) · **경매 물량**(상자 · 마리, −0.1 × 변화율, 최대 ±3%)을 더합니다 (계수는 채점 전 가정값).
    하루치씩 불러야 해서(요청마다 하루 1,000번 한도) 주말은 건너뛰고 지난 날짜는 `cache/` 에 영구 보관합니다. 키가 없으면 이 두 이유와 등급표만 빠집니다.
  - 차트 칸은 야채와 같음: 7일 예측 · 행사 · 공휴일, 비는 수산물만 (고기 값은 비 영향이 작음)
- 대형마트 판매가(참가격)는 **2주마다 조사**하고 달마다 파일이 새로 올라옵니다. 서버가 가장 최근 파일을 자동으로 찾고, 처음 받을 때 10초쯤 걸립니다.
  같은 회사 매장은 값이 거의 같아서 회사별 가격으로 보여 주고, 대구 매장은 매장 이름으로 고른 13곳입니다.
- 소매가는 품목마다 단위가 다릅니다 (kg · 개 · 포기). 약 2일 늦게 올라옵니다.
- 제미나이 무료 API는 몰리면 잠깐 바쁘거나 하루 한도에 걸립니다. 그러면 `.env` 의 `GEMINI_FALLBACK_MODELS` 순서대로 다른 모델로 넘어갑니다.
- 식봄 가격은 식봄 검색 결과(기본 배송 지역) 기준이라 대구 배송 판매자 · 가격과 다를 수 있습니다.
  식봄 화면 구조가 바뀌면 `foodspring.py` 를 고쳐야 합니다.

## Vercel 배포 (https://jangbaguni-ten.vercel.app)
GitHub `main` 에 올리면 자동으로 배포됩니다. 처음 한 번만 Vercel 프로젝트 설정이 필요합니다.
1. Vercel → `jangbaguni` 프로젝트 → **Settings → Build and Deployment**
   - **Root Directory**: `salpi_agent`
   - **Framework Preset**: `FastAPI`
2. **Settings → Environment Variables** → 저장소 맨 위 `.env` 내용을 그대로 붙여 넣기 (키는 GitHub에 올리지 않음)
3. **Deployments** → 맨 위 배포 `⋯` → **Redeploy**

- `vercel.json`: FastAPI로 실행, 서울 지역(icn1). 살피 말투(`brand/SKILL.md`)는 GitHub에서 읽어 옴
- Vercel은 `/tmp` 에만 저장할 수 있어 서버가 새로 켜지면 시세를 다시 받습니다 (약 15초)
- 대화 기록은 브라우저가 들고 있다가 질문할 때마다 함께 보냅니다
- 식봄이 자동 접속을 막으면 상품 대신 재료별 식봄 검색 링크가 나옵니다
