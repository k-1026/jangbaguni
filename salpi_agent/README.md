# 살피 · 대구 야채 시세 웹 + AI 에이전트

웹페이지를 열면 **야채 시세 대시보드**(날짜별 시세 · 날씨 · 공휴일 · 대구 행사 반영)와
**오늘의 야채 상품 목록**(누르면 식봄 검색으로 연결)이 나오고,
오른쪽 아래 **살피 AI 버튼**을 누르면 채팅창이 열립니다. 대화는 구글 제미나이 무료 API를 씁니다.

## 처음 한 번 준비
1. 저장소 맨 위 `.env` 에 키 넣기 (견본: `.env.example`)
   - 공공데이터포털 키 (정산정보 · 일별 도·소매가 · 기상청 · 특일 · 관광공사)
   - `GEMINI_API_KEY` — https://aistudio.google.com → Get API key (무료)
2. 이 폴더에서 설치
   ```
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

## 실행
- `실행.bat` 더블클릭 → 브라우저에서 http://localhost:8000 이 열림
- 또는 `.venv\Scripts\python server.py`
- 주소 끝에 `#chat` 을 붙이면 채팅창이 열린 채로 시작 (시연용)

처음 켤 때는 4주치 시세를 받느라 **2~3분** 걸립니다. 그다음부터는 `cache/` 에 저장된 값을 써서 빠릅니다.

## 화면
| 부분 | 내용 |
|---|---|
| 맨 위 | 로고 자리(비워 둠) · 메뉴 · 기준일 |
| 살피 메인 | 오른 야채 수 · 내린 야채 수 · 다음 주 오를 야채 수 · 가장 많이 오른 야채 |
| 야채 시세 | 재료 탭 → 4주 시세 그래프(강수량 막대 · 행사 띠 · 공휴일 점선 · 다음 7일 예측 범위), 날짜별 가격표(이전대비 ▲▼ · 날씨 · 행사), 예측 이유 |
| 오늘의 야채 | 15개 야채 카드. 누르면 식봄 검색 결과로 이동, '시세 보기'는 위 그래프로 이동 |
| 시세에 영향을 주는 것들 | 대구 7일 날씨 · 30일 안 공휴일 · 14일 안 대구 행사 |
| 살피 AI (오른쪽 아래) | 채팅 + 누르기만 하면 되는 질문 3개 |

### 살피 AI 기본 질문
1. **야채값 시세변동 추이 말해줘.** → 많이 오른·내린 야채와 지금 사기 좋은 야채 추천
2. **이 가격에 팔아도 남아?** → "어떤 메뉴를 만드시는지 알려주세요" → 메뉴 · 판매가를 들으면 1인분 재료비 · 원가율 · 남는 돈 계산
   (표준 레시피: 김치찌개 · 제육볶음 · 된장찌개 · 떡볶이 · 비빔밥 · 부대찌개 · 오징어볶음, 그 밖의 메뉴는 재료와 양을 말하면 계산)
3. **지금 사면 이득인 야채 알려줘** → 미리 살 것 · 지금 싼 것 · 기다릴 것

## 파일
| 파일 | 하는 일 |
|---|---|
| `data_sources.py` | 공공 API 호출 · 캐시, 지원 품목 목록(`ITEMS`), 식봄 검색 주소 |
| `analysis.py` | 시세 변화 · 날짜별 상세 · 다음 7일 예측 · 지금 사기 추천 (숫자는 여기서만 만듦) |
| `menu_cost.py` | 메뉴 1인분 원가 · 원가율, 표준 레시피, 참고 단가 |
| `agent.py` | 제미나이 에이전트: 도구 호출 → 살피 말투로 설명 (`brand/SKILL.md` 적용), 바쁠 때 다른 모델로 자동 전환 |
| `server.py` | 웹 서버 (화면 + `/api/...`) |
| `web/` | 화면 (`index.html` · `style.css` · `app.js` · 살피 이미지) |

## 알아 둘 점
- 예측은 학습 모델이 아니라 **이유를 하나씩 보여 주는 규칙 기반 추정**입니다
  (최근 2주 흐름 · 반입량 · 대구 날씨 · 공휴일 · 대구 행사). 주산지 날씨와 수입량은 아직 반영하지 않았습니다.
- 메뉴 원가의 채소값은 **도매 경락가**라 실제 구매가보다 낮게 나올 수 있고, 고기 · 양념 등은 **시연용 참고 단가**입니다.
- 소매가는 품목마다 단위가 다릅니다 (kg · 개 · 포기). 약 2일 늦게 올라옵니다.
- 제미나이 무료 API는 몰리면 잠깐 바쁘거나 하루 한도에 걸립니다. 그러면 `.env` 의 `GEMINI_FALLBACK_MODELS` 순서대로 다른 모델로 넘어갑니다.
- 상품 카드 배경은 사진 대신 색 칸입니다. 야채 사진이 생기면 `web/app.js` 의 카드 부분만 바꾸면 됩니다.
