# 살피 AI 에이전트 · 시세 대시보드

대구 북부도매시장(매천시장) 시세를 살펴 **올랐는지 · 내렸는지** 보여 주고,
날씨 · 공휴일 · 대구 행사를 더해 **다음 7일 가격 방향**을 알려 주는 에이전트입니다.
대화는 구글 제미나이 무료 API를 씁니다.

## 처음 한 번 준비
1. 저장소 맨 위 `.env` 에 키 넣기 (견본: `.env.example`)
   - 공공데이터포털 키 6개 (정산정보 · 일별 도·소매가 · 기상청 · 특일 · 관광공사)
   - `GEMINI_API_KEY` — https://aistudio.google.com → Get API key (무료)
2. 이 폴더에서 설치
   ```
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```

## 실행
- `실행.bat` 더블클릭 → 브라우저에 대시보드가 열림
- 또는 `.venv\Scripts\streamlit run app.py`
- 터미널에서 대화만: `.venv\Scripts\python agent.py`

처음 열 때는 4주치 시세를 받느라 **2~3분** 걸립니다. 그다음부터는 `cache/` 에 저장된 값을 써서 빠릅니다.

## 화면
| 탭 | 내용 |
|---|---|
| 오늘 시세 | 재료별 도매 kg당 가격과 1주 전 대비 변화, 소매가, 2주 흐름 그래프 |
| 다음 주 예측 | 오를/내릴/비슷 + 예상 범위 + 이유(요인별 %) |
| 날씨 · 행사 | 대구 2주 날씨, 30일 안 공휴일, 14일 안 대구 행사 |
| 살피에게 물어보기 | "양파 요즘 올랐어?", "대파 다음 주에 오를까?" 같은 질문, 아침 브리핑 |

## 파일
| 파일 | 하는 일 |
|---|---|
| `data_sources.py` | 공공 API 호출 · 캐시, 지원 품목 목록(`ITEMS`) |
| `analysis.py` | 시세 변화 계산, 다음 7일 예측 (숫자는 여기서만 만듦) |
| `agent.py` | 제미나이 에이전트: 도구 호출 → 살피 말투로 설명 (`brand/SKILL.md` 적용) |
| `app.py` | 대시보드 화면 (Streamlit) |

## 알아 둘 점
- 예측은 학습 모델이 아니라 **이유를 하나씩 보여 주는 규칙 기반 추정**입니다
  (최근 2주 흐름 · 반입량 · 대구 날씨 · 공휴일 · 대구 행사). 주산지 날씨와 수입량은 아직 반영하지 않았습니다.
- 지원 품목: 양파 · 대파 · 양배추 · 청양고추 · 당근 · 깻잎. 늘리려면 `data_sources.py` 의 `ITEMS` 에 한 줄 추가
  (perDay는 KAMIS 품목 코드, 정산정보는 품목 이름).
- 소매가(일별 도·소매가)는 약 2일 늦게 올라옵니다.
